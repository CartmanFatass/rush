# 国考真题库（近 5 年 · 行测 + 申论）

2022–2026 年国家公务员录用考试真题，共 **30 套**：
行测 15 套（1975 题，答案 1975 条，全覆盖）+ 申论 15 套。

> 年份口径：国考以考试年度命名（2026 国考 = 2025 年 11 月 30 日笔试）。
> 抓取时间 2026-11-01，2027 国考尚未开考，故「近 5 年」= 2022–2026。

## 目录

```

└── scripts/                   抓取与解析脚本
```

## 数据来源

- 站点：公开真题库 <https://gwy.gkzhenti.cn>（原 `gkzenti.cn`）
- 试卷列表走站点公开的 JSON 接口：`/api/json?cls=行测&province=国考`
- 题干来自 `/paper/{id}`，答案来自 `/answer/{id}`，均为站点公开免费页面
- 图片原图托管于 `upload.gkzhenti.cn`，已全部转存到 `assets/`，Markdown 内为相对路径，可离线阅读

## 已知限制

1. **题源为「网友回忆版」**。国考官方从不公布真题，市面所有真题都是考生回忆整理，个别题目文字、选项顺序可能与原卷有出入，个别题目可能缺失。这是所有渠道的共同限制。
2. **未收录解析**。站点的解析属会员付费内容（每套仅免费试读 30 余题），本次只取题目与答案。
3. **申论的划线句子**在纯文本中不保留下划线样式，但题干会引用该句原文，可对应。
4. 数学公式、图形推理、资料分析图表均为图片，非可编辑文本。

## 配套讲义

`讲义链接.md` 收录了 33 条 2025–2026 年行测/申论讲义（粉笔 980、花生十三、单项技巧）的夸克网盘链接，全部经过存活验证。真题 + 讲义配套使用效果最好。

## 脚本

```bash
cd scripts
python3 scrape.py     # 联网抓取全部 30 套（重建 assets 与 md/json）
python3 rebuild.py    # 离线重建：只从已有 json 重新渲染 md，不联网
```

依赖：`requests`、`beautifulsoup4`、`lxml`。
