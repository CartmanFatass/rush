## 工作模型：一条政策链，三个取样点

判断（讲话、全会：提出矛盾和关系）→ 部署（文件：目标、任务、机制）→ 落实（部委方案、地方试点）→ 呈现（官媒：经验报道、问题调查、评论）→ 纠偏与固化（通报、督查、立法）。

这是组织阅读的待检验模型：时政可从准确命题入手，小题可对照案例及规范概括，作文可分析关系和评论的展开方式。不能把三类题限定在某一阶段，也不能由字面相似推出取材或传播链。
