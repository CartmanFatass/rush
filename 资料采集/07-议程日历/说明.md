## 3. 逐字状态

新口径：A＝原文已存进本目录 `raw/`，引文能在里面逐字找到；B＝没存原文但两处独立来源一致；C＝单一来源或转述。

本目录三张表里带「逐字状态」的两张（深改委会议目录 23 条、年度政治日历 102 条）全部标 A，因为每条的 URL 都抓了原文存进 `raw/`。这两张表没有需要逐字比对的引文类键，A 的实际含义是「通稿原文已存档，可复核」。印发追踪表没有该键。

## 4. 口径与约定（做时间差分析前请先看这一节）

1. **日期取会议召开首日**。多日会议在「名称」里写起止日（如「2021年11月8日-11日」）。起止日均已从通稿正文或公报正文核对，不是从 URL 推的。
2. **深改委、财经委的「届次」「序次」**：通稿标题多数不写第几次，序次按 12371 专栏索引的时间顺序推定，并与人民网资料中心「二十届中央全面深化改革委员会会议」「二十届中央财经委员会会议」两个编号索引页对照一致。二十届第一次通稿标题明写「二十届中央全面深化改革委员会第一次会议」，其余各次据此接续。
3. **「公开印发日期」取 gov.cn 发布页的发布日期**，不取文件成文日期（成文日期通常早几天到几个月）。例如《关于深化医疗保障制度改革的意见》发布页 2020-03-05，文内成文日期更早。做「审议—印发」间隔时用的是发布页日期，口径统一。
4. **「文件名」逐字取会议通稿里的写法**；实际印发页标题有 8 件与审议名不完全一致，属同一文件的不同表述，已在下面列出，核对时不要当成两个文件：
   | 审议名（通稿） | 印发页标题 |
   |---|---|
   | 《关于加快推进媒体深度融合发展的指导意见》 | 关于加快推进媒体深度融合发展的意见 |
   | 《关于深化国有文艺院团改革的实施意见》 | 关于深化国有文艺院团改革的意见 |
   | 《关于在城乡建设中加强历史文化保护传承的若干意见》 | 关于在城乡建设中加强历史文化保护传承的意见 |
   | 《关于加强科技伦理治理的指导意见》 | 关于加强科技伦理治理的意见 |
   | 《新时代加强和改进思想政治工作的意见》 | 关于新时代加强和改进思想政治工作的意见 |
   | 《关于进一步提升基层应急管理能力的意见》 | 关于进一步提升基层应急管理能力的意见（同） |
   | 《关于加强生态环境分区管控的指导意见》 | 关于加强生态环境分区管控的意见 |
   | 《关于促进经济社会发展全面绿色转型的意见》 | 关于加快经济社会发展全面绿色转型的意见 |
   | 《关于深化我国医疗保障制度改革的意见》 | 关于深化医疗保障制度改革的意见 |
5. **讲话全文页的日期**：少数条目（文化传承发展座谈会、冬奥总结表彰大会、香港回归25周年大会）的 URL 是《讲话》全文页，页面发布日比会议日晚 1 天到 3 个月。这类条目的「日期」填会议日，并在「名称」里注明讲话刊发日，避免把发布日误当会议日。其余条目 URL 日期与会议日一致。
6. **年度政治日历中「政府工作报告」一行同时充当当年全国两会开幕日的标记**（报告在两会开幕日作）。两会本体的议程、政协会议、闭幕日没有单列，见第 6 节缺口。

| 区间 | 件数 |
|---|---|
| 0–3 个月 | 15 |
| 3–6 个月 | 13 |
| 6–9 个月 | 2 |
| 9–12 个月 | 2 |

- 41 件未查到公开印发页，`印发URL` 留空。其中一部分是确实没有公开发布全文（如《种业振兴行动方案》《科技体制改革三年攻坚方案》《关于强化企业科技创新主体地位的意见》《关于加强基础学科人才培养的意见》等深改委审议件），另一部分是**只在部委官网发布、gov.cn 中央文件库没有收录**（如《关于深化体教融合促进青少年健康发展的意见》由体育总局、教育部印发；《关于进一步规范医疗行为促进合理医疗检查的指导意见》由卫健委等八部门印发）。后者不是「没有印发」，是「本次没有逐件去部委网站核」。检索方式为 gov.cn 政策库标题检索，逐件试了 2–4 组关键词。

### 6.5 方法上的限制
- gov.cn 政策库的检索接口只对「标题」字段有效，且对标题里的修饰词敏感（例如检索「关于完善农业支持保护制度的意见」为 0 条，检索「农业支持保护」也是 0 条），所以「未查到」不等于「不存在」。每件的检索词已尽量退到核心名词短语。
- 12371 的站内搜索是 JS 动态页、iframe 加载，抓不到结果列表；gov.cn 的会议新闻不在政策库里。因此领域性会议、纪念大会只能靠 12371 的静态专栏索引和讲话索引逐条找，覆盖不全。
- 未使用任何需要登录或付费的数据库。
