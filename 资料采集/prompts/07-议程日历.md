# 采集任务 07：议程目录：深改委、财经委与年度政治日历

你是资料采集员。这份任务书是自足的，不需要别的上下文。只做采集和整理，不写学习建议，不做预测。

## 背景

一位考生在研究国家公务员考试（国考）的三类题——行测时政题、申论小题（概括、分析、对策）、申论大作文——和党政会议、文件、官媒稿件之间的关系，用于学习，不用于押题。研究用的工作模型是"一条政策链，三个取样点"：

判断（讲话、全会）→ 部署（文件）→ 落实（部委方案、地方试点）→ 呈现（官媒报道和评论）→ 纠偏与固化（通报、立法）

行测时政题取前两段的原句；申论小题取后三段的案例，要求用"部署"那一段的语言复述；大作文取"判断"里的一对关系，用官媒评论体写出来。

你采的这块资料，用来核对两个时间差。已经观察到：行测时政题多出自考前一年内的讲话和文件；申论材料写的多是一两年前出台的改革方案在基层的落实情况。需要一份可靠的"议程目录"，才能量"会议审议—文件印发—进入考卷"各隔多久。

## 工作位置

仓库根目录 `rush/`（Windows 上是 `C:\Projects\rush`）。下面的路径都相对仓库根目录。只在 `资料采集/07-议程日历/` 里写文件，不改别的文件，不提交 git。

## 通用规则

1. **不编造。** 每条记录都要有出处名称、发布日期（YYYY-MM-DD，查不到写"不详"）和 URL。查不到就写"未找到"，并记下试过的检索词。标题、日期、链接、引文一律不许凭记忆补；你自己的推断写成"判断"。
2. **来源分级。** 党和政府官网（gov.cn、12371.cn、qstheory.cn、scs.gov.cn、各部委官网）和新华社、人民日报、光明日报、经济日报、半月谈等官媒，高于地方党报和地方政府网，再高于门户转载。培训机构网页（华图、中公、粉笔等）只能当线索，不能当官方事实的出处；确需引用就写明"机构"。
3. **引文分级。** 每条引文标"逐字状态"：A＝原文已存进本任务目录的 `raw/`，引文能在里面逐字找到；B＝没存原文，但在两处独立来源看到一致的文字；C＝单一来源，或经摘要工具转述，未核对。能抓到网页原文就存：党和政府的文件、会议通稿、讲话存全文（文件名 `日期_来源_标题.txt`，首行写 URL）；新闻报道和评论同样存全文（文件名规则相同）。
4. **数据格式。** 数据文件用 JSON Lines（一行一个 JSON 对象，UTF-8），键名用任务书给的中文键，缺的值写空字符串。做完一部分就落盘。
5. **做不完怎么办。** 先保证已做的部分准确，再求全。在 `说明.md` 里写清做到哪里、哪些没做、哪些站点抓不到。
6. **检索技巧。** 官方网站直接抓原件，不必找转载页。检索时用材料里不容易改写的细节，比泛泛的主题词有效得多。

## 任务

时间范围 2019-11 至 2026-11。以新华社通稿为准（新华网、中国政府网、共产党员网、人民网的转载均可）；百科类页面只能当线索，逐条回到通稿核对。文件名要逐字。

### 1. 中央全面深化改革委员会会议目录

十九届后半段和二十届。每次会议一条，键：届次, 序次, 日期, 审议通过的文件（数组，文件全名）, 通稿URL, 逐字状态。

然后对其中面向社会治理、民生、乡村、生态、文化、科技、教育、产业、城市的文件，逐个查它后来公开印发的情况，另存一张表，键：文件名, 审议日期, 公开印发日期, 印发机关, 印发URL, 审议到印发的月数。没有公开印发的留空。

### 2. 中央财经委员会会议目录

键：届次, 序次, 日期, 议题（数组）, 通稿要点（一句）, 通稿URL。

### 3. 年度政治日历

2020–2026 每年一组，收这些类别：

- 党的全会（含通过的文件）
- 中央经济工作会议、中央农村工作会议、中央一号文件（标题）
- 全国两会和政府工作报告
- 每年 4 月、7 月、12 月分析研究经济形势的中央政治局会议
- 当年召开的领域性中央会议和全国性大会（如中央人才工作会议、全国生态环境保护大会、全国宣传思想文化工作会议、中央金融工作会议、全国新型工业化推进大会、全国科技大会、全国教育大会、中央城市工作会议、全国卫生与健康大会、中央社会工作会议等，以实际召开为准）
- 总书记主持召开的重要座谈会
- 逢五逢十的纪念大会和重要周年
- 当年开展的党内集中教育
- 当年出台的五年规划类文件

键：年份, 日期, 类别, 名称, 通过或发布的文件, 通稿URL, 逐字状态。

### 4. 两项简单统计

写进 `说明.md`：深改委审议到公开印发的月数分布；每年领域性中央会议的数量和月份分布。
