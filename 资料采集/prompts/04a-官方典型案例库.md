# 采集任务 04a：官方典型案例库与官方概括的写法

你是资料采集员。这份任务书是自足的，不需要别的上下文。只做采集和整理，不写学习建议，不做预测。

## 背景

一位考生在研究国家公务员考试（国考）的三类题——行测时政题、申论小题（概括、分析、对策）、申论大作文——和党政会议、文件、官媒稿件之间的关系，用于学习，不用于押题。研究用的工作模型是"一条政策链，三个取样点"：

判断（讲话、全会）→ 部署（文件）→ 落实（部委方案、地方试点）→ 呈现（官媒报道和评论）→ 纠偏与固化（通报、立法）

行测时政题取前两段的原句；申论小题取后三段的案例，要求用"部署"那一段的语言复述；大作文取"判断"里的一对关系，用官媒评论体写出来。

你采的这块资料，用来给申论"概括做法"类题目找官方对照。申论的给定资料很像匿名化之后的官方典型案例；这类题的答案，很像官方对一个案例做法的概括。国考不公布答案，市面答案都出自培训机构；官方自己写的案例概括，是能找到的最接近"标准写法"的东西。

## 通用规则

1. **不编造。** 每条记录都要有出处名称、发布日期（YYYY-MM-DD，查不到写"不详"）和 URL。查不到就写"未找到"，并记下试过的检索词。标题、日期、链接、引文一律不许凭记忆补；你自己的推断写成"判断"。
2. **来源分级。** 党和政府官网（gov.cn、12371.cn、qstheory.cn、scs.gov.cn、各部委官网）和新华社、人民日报、光明日报、经济日报、半月谈等官媒，高于地方党报和地方政府网，再高于门户转载。培训机构网页（华图、中公、粉笔等）只能当线索，不能当官方事实的出处；确需引用就写明"机构"。
3. **引文分级。** 每条引文标"逐字状态"：A＝原文已存进本任务目录的 `raw/`，引文能在里面逐字找到；B＝没存原文，但在两处独立来源看到一致的文字；C＝单一来源，或经摘要工具转述，未核对。能抓到网页原文就存：党和政府的文件、会议通稿、讲话存全文（文件名 `日期_来源_标题.txt`，首行写 URL）；新闻报道和评论同样存全文（文件名规则相同）。
4. **数据格式。** 数据文件用 JSON Lines（一行一个 JSON 对象，UTF-8），键名用任务书给的中文键，缺的值写空字符串。做完一部分就落盘。
5. **做不完怎么办。** 先保证已做的部分准确，再求全。在 `说明.md` 里写清做到哪里、哪些没做、哪些站点抓不到。
6. **检索技巧。** 官方网站直接抓原件，不必找转载页。检索时用材料里不容易改写的细节，比泛泛的主题词有效得多。

## 任务

### 1. 目录

2019–2026 年国务院办公厅和各部委公开发布的"典型案例、典型经验、优秀案例、经验做法清单、示范名单"类文件。下面每个领域找 3 份以上：

乡村振兴与乡村治理；县域发展与城乡融合；基层治理；生态产品价值实现与生态文明；城市更新与城市治理；公共文化服务与文旅融合；非遗和文物活化利用；养老和托育；基层医疗卫生；教育（五育并举、劳动教育、"双减"）；就业与新就业形态；科技创新与成果转化；科学普及；制造业（专精特新、单项冠军、老字号）；数字经济与数据要素（含数据标注）；交通物流（四好农村路、多式联运、交通旅游融合）；营商环境与政务服务；知识产权；集体林权和自然资源；水利（数字孪生、河湖长制）；应急与安全生产。

另外，国务院大督查和国务院办公厅历年的"典型经验做法通报"逐年列出。

每条的键：领域, 名称, 发布机关, 日期, 案例数, URL, 单个案例的固定结构（照文件实际写，如"背景—做法—成效—启示"）, 备注。

### 2. 采样

从不同领域挑 30 个官方案例，优先选官方自己写了概括、带小标题的。每个案例的键：领域, 案例名, 所属文件, URL, 做法小标题（数组，原文）, 每条做法的首句（数组，原文）, 成效表述（一句，原文）, 全案字数（估计）, 逐字状态, 原文文件。

然后写一份描述统计（只描述，不评价）：做法小标题平均几个字，是不是动宾结构；一个案例通常列几条做法，每条几句话；成效用数字还是定性表述；有没有固定的收尾（启示、下一步）。

### 3. 同题检查

下面这些题材在近五年国考申论里出现过。逐个查有没有官方案例，有就优先收进采样，并在记录里写明"与国考同题"：

生态产品价值核算（GEP）；林票或集体林权改革；数字孪生流域；城市传统葡萄园等农业文化遗产；政企合作治水；数据标注产业；暗夜星空保护与天文观测；老字号创新发展；铁路专用线与多式联运；农村闲置农房盘活或"共享村落"；公众参与科学研究；整县屋顶分布式光伏；知识产权信息服务；高标准农田建设；基层卫生人才"县管乡用"；新型公共文化空间；艺术乡建；交通旅游融合服务区；农村公路"建管养运"；"五育"融合。

`资料采集/01-材料溯源/` 里如果已经查出了某则材料的真实原型（如青海冷湖、河北宣化、贵州清镇花鱼洞大桥、甘肃庆阳、上海"貉口普查"），直接按原型去找它的官方概括。
