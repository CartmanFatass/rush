# 采集任务 04b：官方问题通报库与两张词表

你是资料采集员。这份任务书是自足的，不需要别的上下文。只做采集和整理，不写学习建议，不做预测。

## 背景

一位考生在研究国家公务员考试（国考）的三类题——行测时政题、申论小题（概括、分析、对策）、申论大作文——和党政会议、文件、官媒稿件之间的关系，用于学习，不用于押题。研究用的工作模型是"一条政策链，三个取样点"：

判断（讲话、全会）→ 部署（文件）→ 落实（部委方案、地方试点）→ 呈现（官媒报道和评论）→ 纠偏与固化（通报、立法）

行测时政题取前两段的原句；申论小题取后三段的案例，要求用"部署"那一段的语言复述；大作文取"判断"里的一对关系，用官媒评论体写出来。

你采的这块资料，用来给申论"问题加对策"类题目找上游。这类题用的材料，写的多是官方明确反对的做法（一刀切、重建轻管、形式主义等）。要拿到官方自己怎样给问题定性、归类、提整改要求：定性的词用来归纳问题，整改的词用来写对策。

## 工作位置

仓库根目录 `rush/`（Windows 上是 `C:\Projects\rush`）。下面的路径都相对仓库根目录。只在 `资料采集/04-官方案例与通报/` 里写文件，不改别的文件，不提交 git。

## 通用规则

1. **不编造。** 每条记录都要有出处名称、发布日期（YYYY-MM-DD，查不到写"不详"）和 URL。查不到就写"未找到"，并记下试过的检索词。标题、日期、链接、引文一律不许凭记忆补；你自己的推断写成"判断"。
2. **来源分级。** 党和政府官网（gov.cn、12371.cn、qstheory.cn、scs.gov.cn、各部委官网）和新华社、人民日报、光明日报、经济日报、半月谈等官媒，高于地方党报和地方政府网，再高于门户转载。培训机构网页（华图、中公、粉笔等）只能当线索，不能当官方事实的出处；确需引用就写明"机构"。
3. **引文分级。** 每条引文标"逐字状态"：A＝原文已存进本任务目录的 `raw/`，引文能在里面逐字找到；B＝没存原文，但在两处独立来源看到一致的文字；C＝单一来源，或经摘要工具转述，未核对。能抓到网页原文就存：党和政府的文件、会议通稿、讲话存全文（文件名 `日期_来源_标题.txt`，首行写 URL）；新闻报道和评论同样存全文（文件名规则相同）。
4. **数据格式。** 数据文件用 JSON Lines（一行一个 JSON 对象，UTF-8），键名用任务书给的中文键，缺的值写空字符串。做完一部分就落盘。
5. **做不完怎么办。** 先保证已做的部分准确，再求全。在 `说明.md` 里写清做到哪里、哪些没做、哪些站点抓不到。
6. **检索技巧。** 官方网站直接抓原件，不必找转载页。检索时用材料里不容易改写的细节，比泛泛的主题词有效得多。

## 任务

### 1. 整治形式主义为基层减负的历次通报

中央层面整治形式主义为基层减负专项工作机制公开通报的典型问题，2019 年至今的全部批次。每个典型问题一条，键：来源类别（填"基层减负通报"）, 批次, 通报日期, 问题标题（原文）, 涉及领域, 定性用语（数组，通报给问题下判断的原话）, 整改要求用语（数组，原话）, URL, 逐字状态, 原文文件。

### 2. 其他官方通报的问题类典型案例

来源：国务院大督查和国办督查室、国家发展改革委、农业农村部、自然资源部、生态环境部（中央生态环境保护督察典型案例）、住房城乡建设部、民政部、国家能源局、审计署公告等。2020 年以来各取有代表性的 3–10 例。键同上，"来源类别"填发布机关。

优先找与下面这些申论材料同题的：

- 高标准农田建设的质量和选址问题（2024 年副省级卷；原型疑为甘肃庆阳（线索，未核实），2023 年 3 月中国之声曝光，农业农村部随后回应并开展专项整治）
- 整县屋顶分布式光伏开发中的垄断和强制（2023 年地市级卷，"一企包一县"）
- 农村公路重建轻养、多头管理（2022 年地市级卷）
- 公共文化设施重建轻管、利用率低、同质化（2024 年地市级卷）
- 养老机构整治中的"一刀切"（2026 年副省级卷，家庭式养老机构被限期停业）
- 闲置农房和宅基地盘活中的纠纷和违规（2026 年地市级卷）
- 政务 App 和数据填报的"指尖上的形式主义"
- 文旅项目盲目上马、乡村建设大拆大建
- 林权流转中的估值难、流转难（2025 年地市级卷）

### 3. 两张词表

由上面的材料归纳，每个词都要带官方原句和出处，不收只在培训机构资料里出现的词。

- 问题定性词表，60 个以上。例如层层加码、一刀切、重建轻管、政绩工程、形象工程、多头管理、推诿扯皮、数字形式主义、新官不理旧账、简单化、运动式。键：词, 含义（一句，你的概括）, 官方原句（不超过 80 字）, 出处, 日期, URL, 出现于哪些通报（数组）, 逐字状态。
- 整改和对策手段词表，80 个以上。例如建立台账、销号管理、工作专班、联审联办、过渡期、缓冲期、分类处置、容缺受理、举一反三、长效机制、回头看、压实责任、清单管理。键同上。
