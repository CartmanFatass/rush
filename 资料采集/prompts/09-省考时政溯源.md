# 采集任务 09：省考时政题的出题依据标注

你是资料采集员。这份任务书是自足的，不需要别的上下文。只做采集和整理，不写学习建议，不做预测。

## 背景

一位考生在研究国家公务员考试（国考）的三类题——行测时政题、申论小题（概括、分析、对策）、申论大作文——和党政会议、文件、官媒稿件之间的关系，用于学习，不用于押题。研究用的工作模型是"一条政策链，三个取样点"：

判断（讲话、全会）→ 部署（文件）→ 落实（部委方案、地方试点）→ 呈现（官媒报道和评论）→ 纠偏与固化（通报、立法）

行测时政题取前两段的原句；申论小题取后三段的案例，要求用"部署"那一段的语言复述；大作文取"判断"里的一对关系，用官媒评论体写出来。

你采的这块资料，用来把"时政题出自哪些文件、文件发布多久之后被考"的样本，从国考 74 题扩大到省考。这一项主要靠读解析和写脚本，只有笔试日期和文件发布日期需要上网查。

## 工作位置

仓库根目录 `rush/`（Windows 上是 `C:\Projects\rush`）。下面的路径都相对仓库根目录。只在 `资料采集/09-省考时政溯源/` 里写文件，不改别的文件，不提交 git。

## 通用规则

1. **不编造。** 每条记录都要有出处名称、发布日期（YYYY-MM-DD，查不到写"不详"）和 URL。查不到就写"未找到"，并记下试过的检索词。标题、日期、链接、引文一律不许凭记忆补；你自己的推断写成"判断"。
2. **来源分级。** 党和政府官网（gov.cn、12371.cn、qstheory.cn、scs.gov.cn、各部委官网）和新华社、人民日报、光明日报、经济日报、半月谈等官媒，高于地方党报和地方政府网，再高于门户转载。培训机构网页（华图、中公、粉笔等）只能当线索，不能当官方事实的出处；确需引用就写明"机构"。
3. **引文分级。** 每条引文标"逐字状态"：A＝原文已存进本任务目录的 `raw/`，引文能在里面逐字找到；B＝没存原文，但在两处独立来源看到一致的文字；C＝单一来源，或经摘要工具转述，未核对。能抓到网页原文就存：党和政府的文件、会议通稿、讲话存全文（文件名 `日期_来源_标题.txt`，首行写 URL）；新闻报道和评论同样存全文（文件名规则相同）。
4. **数据格式。** 数据文件用 JSON Lines（一行一个 JSON 对象，UTF-8），键名用任务书给的中文键，缺的值写空字符串。做完一部分就落盘。
5. **做不完怎么办。** 先保证已做的部分准确，再求全。在 `说明.md` 里写清做到哪里、哪些没做、哪些站点抓不到。
6. **检索技巧。** 官方网站直接抓原件，不必找转载页。检索时用材料里不容易改写的细节，比泛泛的主题词有效得多。

## 材料

- GitHub 仓库 `ERRRC/xingcezhenti`：2016–2026 年国考和省考行测真题与解析（考生回忆版，解析由培训机构整理），按模块拆成单文件。仓库较大，用浅克隆，必要时只取需要的文件。先摸清目录结构和文件命名规则，写进说明。
- `analysis/out/source_lag.csv`：国考 74 题的既有逐题标注（依据类型、依据名称、依据发布日期、距考试月数、题型、专题）。`analysis/source_lag.py` 是生成它的脚本。先读这两个，你的标注口径要和它们一致。

## 范围

2024、2025、2026 年度各省公务员考试行测里的"政治理论"模块题，以及"常识判断"里考时政的题（考当年或近年的会议、文件、讲话、重大事件的；纯科技、地理、历史、法律常识不算）。

多省联考里各省共用的题只算一次：按题干去重，记下出现在哪些省。仓库里省考卷很多、做不完时，优先多省联考各卷、北京、上海、江苏、浙江、广东、山东、四川、深圳，并先把 2026、2025 年度做完整。

## 每道题的标注

键：年度, 考试（多省联考/某省）, 卷别, 出现省份（数组）, 笔试日期, 模块（政治理论/常识判断）, 题干前60字, 题型（选对/选错/几项/排序对应/其他）, 依据名称（按解析所写的文件、讲话、会议）, 依据类型, 依据发布日期, 距笔试月数, 专题, 备注。

- 依据类型七类：A 党代会或全会文件；B 中央会议通稿或会上讲话；C《求是》等署名文章；D 重要讲话（座谈会、集体学习、周年大会、外交场合）；E 地方考察、回信、贺词；F 政府文件、规划、党内法规、法律；G 基本原理、党史等无时效来源。
- 专题：现代化总论与高质量发展/科技创新/内需与经济体制改革/金融/党的建设/民生与人口/乡村与城乡融合/生态绿色/法治与开放/文化建设/原理与方法论/国家安全/政治制度/其他。
- 解析没写出处的，依据名称填"解析未注明"；发布日期查不实的留空；你自己推断的出处写进备注并标"判断"。
- 各年联考日期和各独立命题省市的笔试日期要上网查实，来源写进说明。
- 讲话常被《求是》重刊。解析写《求是》的按 C 类记，日期记刊发日期，并在备注里写原讲话日期。`资料采集/03-关系对与方法论/求是署名文章目录.jsonl` 如果已经有了，用它核对。

## 统计

写进 `统计.md`：各年度去重后的题量；依据类型分布；距笔试月数的中位数，以及不超过 6、12、18 个月和超过 24 个月的比例；被考两题以上的同一份文件；题型分布；专题分布；和国考同年度卷（用 `source_lag.csv` 的数字）并排对比。

## 输出

目录 `资料采集/09-省考时政溯源/`：`省考时政题溯源.jsonl`、`统计.md`、`说明.md`（仓库结构、筛题和去重方法、笔试日期的查证来源、没做的省份）、`scripts/`（你写的脚本）。

## 验收

我会抽查：URL 能否打开；日期和页面是否一致；A 级引文能否在 `raw/` 里逐字找到；抽 20 道题对着解析看依据名称和类型标得对不对；笔试日期是否有出处；抽查不过的记录作废。交付前先跑 `python3 资料采集/check_collect.py 资料采集/你的目录`，把它报出的格式问题改掉。
