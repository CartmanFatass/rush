# 采集任务 08：官方出的时政选择题

你是资料采集员。这份任务书是自足的，不需要别的上下文。只做采集和整理，不写学习建议，不做预测。

## 背景

一位考生在研究国家公务员考试（国考）的三类题——行测时政题、申论小题（概括、分析、对策）、申论大作文——和党政会议、文件、官媒稿件之间的关系，用于学习，不用于押题。研究用的工作模型是"一条政策链，三个取样点"：

判断（讲话、全会）→ 部署（文件）→ 落实（部委方案、地方试点）→ 呈现（官媒报道和评论）→ 纠偏与固化（通报、立法）

行测时政题取前两段的原句；申论小题取后三段的案例，要求用"部署"那一段的语言复述；大作文取"判断"里的一对关系，用官媒评论体写出来。

你采的这块资料，用来给行测"政治理论"模块找对照样本和练习材料。国考时政题是在文件原句上出题，错误选项多是换一个词。党政机关、党校、工会、高校党委自己出的"应知应会"题，是同一批文件上的另一套出题实践。

## 工作位置

仓库根目录 `rush/`（Windows 上是 `C:\Projects\rush`）。下面的路径都相对仓库根目录。只在 `资料采集/08-时政题库/` 里写文件，不改别的文件，不提交 git。

## 通用规则

1. **不编造。** 每条记录都要有出处名称、发布日期（YYYY-MM-DD，查不到写"不详"）和 URL。查不到就写"未找到"，并记下试过的检索词。标题、日期、链接、引文一律不许凭记忆补；你自己的推断写成"判断"。
2. **来源分级。** 党和政府官网（gov.cn、12371.cn、qstheory.cn、scs.gov.cn、各部委官网）和新华社、人民日报、光明日报、经济日报、半月谈等官媒，高于地方党报和地方政府网，再高于门户转载。培训机构网页（华图、中公、粉笔等）只能当线索，不能当官方事实的出处；确需引用就写明"机构"。
3. **引文分级。** 每条引文标"逐字状态"：A＝原文已存进本任务目录的 `raw/`，引文能在里面逐字找到；B＝没存原文，但在两处独立来源看到一致的文字；C＝单一来源，或经摘要工具转述，未核对。能抓到网页原文就存：党和政府的文件、会议通稿、讲话存全文（文件名 `日期_来源_标题.txt`，首行写 URL）；新闻报道和评论同样存全文（文件名规则相同）。
4. **数据格式。** 数据文件用 JSON Lines（一行一个 JSON 对象，UTF-8），键名用任务书给的中文键，缺的值写空字符串。做完一部分就落盘。
5. **做不完怎么办。** 先保证已做的部分准确，再求全。在 `说明.md` 里写清做到哪里、哪些没做、哪些站点抓不到。
6. **检索技巧。** 官方网站直接抓原件，不必找转载页。检索时用材料里不容易改写的细节，比泛泛的主题词有效得多。

## 这项任务的来源特例

只收党政机关、党校、工会、共青团、高校党委宣传部、国有企业党委等单位公开发布的题库，以及学习强国相关的公开题库。培训机构出的模拟题不收。抄题保持原样，不改写题干和选项。

## 任务

### 1. 题库目录

找公开发布的"应知应会、知识竞赛、学习测试、知识问答"题库，主题限定为：

- 党的二十大报告
- 二十届三中全会《决定》
- 二十届四中全会"十五五"规划建议
- 二十届五中全会关于全面从严治党的《决定》（2026 年 10 月）
- 2024、2025、2026 年政府工作报告
- 2023、2024、2025 年中央经济工作会议
- "十五五"规划纲要
- 习近平经济思想、文化思想、生态文明思想、法治思想的学习纲要

每个主题 2–4 套。键：主题, 题库名称, 发布单位, 日期, URL, 题量, 题型构成（单选、多选、判断、填空各多少）, 是否附答案, 备注。

### 2. GitHub 上的公开题库

"学习强国题库"一类的仓库：仓库名, 地址, 题量, 最近更新时间, 许可证, 数据格式, 备注。只看结构、取少量样本。

### 3. 抽样题

从第 1 部分的题库抽 150 道单选或多选题，各主题大致均衡。键：主题, 题型, 题干, 选项（数组）, 答案, 所考文件, 发布单位, URL。

### 4. 出题方式统计

只描述，不评价。对抽样题逐题看：

- 正确项和文件原句是什么关系（原句照搬/缩写/改写）；
- 错误项是怎么造的（换关键词/顺序或对应颠倒/方向反转/张冠李戴/凭空添加/其他），各占多少；
- 题干的问法（填空式、"下列说法正确的是"、"下列说法错误的是"、数几项正确等）各占多少；
- 题干和选项的平均字数。

再读 `analysis/out/pt.json`（2022–2026 年国考行测政治理论 74 题全文），对同样几项做统计，两边并排列一张表。国考题错误选项的既有分类见 `素材库/README.md` 的"出题规律"一节，口径保持一致：换关键词、顺序或对应颠倒、方向反转。

## 输出

目录 `资料采集/08-时政题库/`：`题库目录.jsonl`、`github题库.jsonl`、`抽样题.jsonl`、`出题方式统计.md`、`说明.md`。

## 验收

我会抽查：URL 能否打开；日期和页面是否一致；A 级引文能否在 `raw/` 里逐字找到；题库发布单位是不是党政机关或其所属单位；抽样题是否与原页面一致；抽查不过的记录作废。交付前先跑 `python3 资料采集/check_collect.py 资料采集/你的目录`，把它报出的格式问题改掉。
