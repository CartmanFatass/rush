## 没做到的，以及为什么

1. **官方"试题特点""命题专家谈"稿件：五场都没有，判断是根本不存在，不是没检索到。** 五场考后通稿（新华社电／国家公务员局稿）内容一律只有考场数、人数、参考率、考录比、监考人数，没有一句谈试题。考后谈申论主题的只有党报（北京日报、羊城晚报、光明网），其"专家"全部是培训机构的人（华图李彬、华图刘有珍、华图李曼卿、中公），已在正文逐条注明"机构"。
2. **2022、2023 两场没有党报对"材料选取"的完整描述**，只有主题和材料清单；行测只有"常识判断全是时事热点""时政热点近半数"这类概括。
3. **表二只收到 4 条，比任务书说的"五六条"少。** 原因是要求 URL 能打开且原文可逐字核对：流传最广的几篇（如"我与申论阅卷官的对话""告诉你申论是如何命题和阅卷的"）都在微信公众号或论坛，抓不到稳定原文，按规则不收。
4. **《中国考试》《中国行政管理》《行政管理改革》上专门研究国考申论评分的论文没找到。** 找到的三篇《中国考试》论文讲的是教育考试主观题网上评阅的通用技术（趋中评分、严厉度漂移、AI 辅助评卷），只有万方/维普摘要，按 C 记。
5. **命题环节没有任何公开点名**，只能到"命题核心专家""命题相关负责人"这一层，且都是 2011 年前后的报道。
6. **部分4 的"常发文报刊"一栏全部填"不详"**：没有按姓名＋单位去知网/万方检索这些教师个人的发文记录，超出本次预算。
7. 未检索的渠道：人民日报、法治日报、中国青年报的考后稿件；各省人社厅/人事考试中心关于"命题专家库""阅卷教师遴选条件"的公开文件。

## 抓不到的站点与绕行办法

1. **国家公务员局门户 www.scs.gov.cn 已于 2026 年 8 月底下线**（页面原话："国家公务员局网站（www.scs.gov.cn）已于8月底下线，后续有关公务员工作的信息将通过中央组织部相关网站进行发布。"）。旧年度大纲页已不可访问。
2. **专题网站 bm.scs.gov.cn/kl20XX 全部 302 到同一个引导页**，正文由 JS 从 `dl.scs.gov.cn` 的接口取。接口只保留当前年度（`/api/index/getExam` 现在只返回 2027 年度两个专题），请求往年 hb01Id 一律返回 `{"exam":"error"}`。
   - 绕行办法一（已用）：从 Internet Archive 取往年专题网站接口 JSON 的存档——2023、2024 年度大纲就是这样拿到的，内容是专题网站原文。
   - 绕行办法二（已用）：2027 年度直接调现行接口 `/api/article/<articleId>`，拿到大纲和公告正文。
   - 绕行办法三（已用）：省级公务员主管部门网站（福建）和市县政府网站（铜仁、南阳卧龙、寻乌、南明）转载的中央大纲全文，均为政府网站，按官方记。
3. **www.scs.gov.cn 首页有 JS 反爬**（`__tst_status` cookie 挑战），本次用 node 执行其脚本算出 cookie 才打开，打开后只看到下线公告。
4. **中国政府网 2021-11-28 那篇《2022年度"国考"开考》已 404**（https://www.gov.cn/xinwen/2021-11/28/content_5653894.htm 实测 404），改用人民政协网转新华网件。
5. **新乡学院、四川司法警官职业学院两处抓取失败**（前者 TLS 握手失败，后者未抓），按 C 记，未存 raw。

- "政治素质"四字不在大纲正文里，只在公告的报考条件；大纲对应的是"政治标准和政治属性"。
