# 赛后通稿与专家解读（五次公共科目笔试）

采集日：2026-11-16。逐字状态按任务书新口径：A＝原文已存进本目录 `raw/`、引文能在里面逐字找到；B＝两处独立来源一致但未存原文；C＝单一来源或经摘要转述。

## 先说结论

1. **五场笔试都找到了官方"笔试举行"通稿**（新华社电或国家公务员局稿），内容一律是考场城市数、考场数、报名确认人数、实际参考人数、参考率、考录比、监考人数，**没有一句涉及试题主题、材料选取或能力导向**。
2. **没有找到任何一篇官方发布的"试题特点"或"命题专家谈"稿件**。国家公务员局和新华社历年考后通稿都不谈试题内容，这一点在 2021–2025 五场里是稳定的（判断）。
3. 描述申论主题、材料、行测政治理论部分的，全部是**党报（北京日报、羊城晚报、光明日报/光明网）在考后一两天的报道**，其"专家"一律是培训机构的人（华图、中公），不是命题或阅卷专家。下表逐条注明。
4. 因此本部分能给出的"官方口径"只有"考试举行了、多少人考"，"试题怎么描述"只能给党报转述＋机构专家，按 C 或 B 标注。

- 摘录（A）：
  > 据考生回忆，上午进行的《行政能力测试》很注重考查考生对时事政治、科技热点的掌握情况。试卷的常识判断部分，几乎全部都是时事热点。比如习近平总书记的“七一”讲话、新冠疫苗、天问一号、脱贫攻坚等均出现在考题当中。其中，关于党史的考查题目数量最多。
  > 下午进行的《申论》是“国考”笔试的重头戏。副省级试卷的主题围绕“创新、未来”展开，5则材料内容分别是：企业科技创新、推进粮食产业发展、乡村旅游产业开发、未来学校教育、播种与未来的收获，全篇材料从多个角度探讨创新升级与未来发展之间的关系。
  > 地市级的申论主题是“融合发展”，几个材料涉及交通旅游融合发展、农村公路养护管理、“五育融合”教育教学改革实践、城乡融合发展等等。
- 文中专家：华图在线"申论"辅导专家李彬（机构）。其原话（A）：
  > 随着时间的推移，公务员考试越来越成熟，近年来主题的设置方面呈现出综合性的特征，不单单考查一个领域的热点。但总的来说都和国家的发展方向相关，一般都围绕经济建设、政治建设、文化建设、社会建设、生态文明建设等“五位一体”去设置材料。
- 该年度大纲行测无"政治理论"部分，报道也未提政治理论。
