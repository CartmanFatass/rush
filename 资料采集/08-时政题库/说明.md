## 三、没做到的，以及为什么

1. **中央经济工作会议只找到 1 套。** 检索出的 2023、2025 年会议题目全部来自培训机构（华图、金标尺、事考帮、莘知教育）和文档售卖站（renrendoc、book118、jinchutou、zhijidoc、gongwen.com.cn、gongwenbang.cn），按任务书的来源特例不收。党政机关自己出的会议题多为"要点梳理""一图读懂"（如天祝县退役军人事务局、山东省信访局、湖南省政协），不是题库。
2. **政府工作报告只有填空题。** 官方渠道（夏河县政府、人民日报微信、全国总工会）发的都是"互动测试 100 题"，逐题挖空给答案，没有选项；带选项的 2024/2025/2026 年报告题库只出现在培训机构页面和文档售卖站，不收。
3. **五中全会没有可抽样的题。** 赣州市司法局那套有完整选项但**不附答案**；洛江区委宣传部那套题目是图片；联勤集结号那套是 50 道填空题。三者都不满足"单选／多选 + 选项 + 答案"，所以抽样 0 道。
4. **十五五规划纲要只有 1 套、3 道可用。** 《纲要》题库多以微信公众号"知识问答"形式发布（如豫直机关党建），微信页本机抓不到。
5. **四个思想纲要只覆盖法治思想。** 经济思想、文化思想、生态文明思想纲要检索到的都是《学习纲要》《学习问答》的目录、书讯或学习体会，没有找到"应知应会／知识测试"题库。
6. **没有逐题核对全部 150 道题与原页面的对应。** 抽取后逐题看过题干、选项、答案是否通顺（发现并修掉了 1 处选项粘连：四川党建第 35 题页面写作"B重大政治任务"，缺分隔符），但没有再逐题回原页比对；A 级引文靠 `raw/` 全文兜底。
7. **GitHub 只取结构与样本**，没有下载全量题库（imutum 的 2.3 MB JSON 只统计了键数和 3 条样本，hydjan 的题库文件托管在 GitHub Pages，未下载）。
8. **本地语料没有题库。** 用 grep 在 `/home/fires/projects/Learn-to-Write/corpus/` 搜过"应知应会／知识竞赛／题库／学习测试"，命中的都是新闻报道（如"举办线上答题竞赛"），没有题库原文，所以本任务全部依赖联网。

## 六、登记口径

- `题库目录.jsonl` 的"发布单位"按页面署名写；转载中央党网／共产党员微信的地方站点，在单位后注明"转载"，并在"来源分级"里标出层级。
- `逐字状态`：A＝原文已存进 `raw/`；C＝题目为图片、只有答案可读，或只取到门户转载页／检索摘要。没有 B 级记录。
- `抽样题.jsonl` 全部 A 级：题干、选项、答案都能在 `raw/` 里逐字找到（`check_collect.py` 已核）。
- "所考文件"按题干内容归到具体文件；四川党建题库里考党章、纪律处分条例的题，按实际出处标注，未一律记成《决定》。
