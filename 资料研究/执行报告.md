## 2. 用户的最新顾虑怎样落实

用户指出，已经考过的题眼不宜直接变成下一轮推荐清单。本轮据此把四件事分开记录：历史题要求完成什么写作任务、近期官方在讨论什么、与已考题眼重合在哪里、当前可以从什么新角度展开。

历史题的用途是确认资料能否支持具体写作动作，以及检查重复。旧题出现次数没有成为推荐加分项。“尚未考到”也没有被换算为概率。与近五年题眼较近的内容移到参照或补充位置；主推荐须另有近期依据、具体机制和新场景。重合检查范围仅为本轮10道市地/副省作文，不能据此声称某概念在所有考试中从未出现。

推荐仍然作出了实质选择，并提供可读材料及其证明作用。每组的“元命题”是可跨场景讨论的认识或方法，政策概念是当前阅读入口，案例用来展开机制、条件及后果；这三层不是同一个标签。

## 3. 三个影响后续资料处理的结果

### 3.1 原词命中，仍可能用反或用错

原词表中有中性名称被标成问题、负面案例中的工具被自动列为措施、相同词形被误配词义等问题。本次直接替换19条的错误含义，并保留原值、理由、原句立场与适用边界。例如建筑区划红线不能解释为原则底线，智媒体不能解释为媒体监督；对台账、考核的批评必须保留目的、方式和对象，不能推广为任何情境下都应使用或禁止这些工具。

提法方面，撤回“高效办成一件事替代放管服”“人工智能+使互联网+失效”“医共体取代医联体”的无依据关系判断，分别记录工作重点、并行或递进、上下位等关系。新旧表述的时间差本身不构成失效证据。

### 3.2 小题需要保存动作、机制、结果和条件

“政企协同”“数字赋能”等概念有压缩作用，但还须能还原需求如何提出、专业能力如何接入、决策怎样形成、信息如何触发处置。成效题则须区分做了什么与产生什么结果；从县域经验写全市实施意见，需要提取机制并保留尺度和适用条件。

因此新入口同时包含正面做法、因果、互动、成效和措施，没有把所有材料都组织成问题清单。共享村落记录的“形式主义/多头管理”过度定性已改为材料能支持的配套、协调等问题；来源候选的低置信和C级状态保持。

### 3.3 频率可以观察，当前证据不足以支持固定权重

《求是》目录对应2019—2026年第22期的190个每期署名文章位置，不能称为该刊全部文章；173条记有网页公开日期，另外17条以刊期暂代并标明。政治局集体学习目录有51条，其中2条为空占位，实质条目49条；年度日历有已知缺口，不进入议题排名。脚本分别报告来源、同期窗口、未命中项和重复原讲话的候选关系，标题词面命中不等于全文强调强度。

省考419题中，330题可按旧日期字段计算，61题超过24个月；另79题归为无时效基本原理/党史，10题缺少可计算日期。超过24个月约占有效日期题18.5%，无时效约占全部题18.9%，二者分母不同。18个月内为249题，占有效日期题75.5%、全部题59.4%。这些结果支持近期资料与长期基础内容并行保留；不能据旧字段把来源日期解释为命题提前量。

等容量阅读清单的事后演示没有显示稳定增益：在2026市地已核样例的6篇《求是》来源中，6个补充阅读席位的两种方案均包含1篇，12个席位均包含3篇；2025年的3席方案加入标题频次后反而漏掉就业篇，6/12席则持平。这里只比较补充阅读篇目的相交，不是整题知识覆盖、答对率或独立预测验证。省考旧字段的对应结果单列，未被用于确定国考权重。具体规则、逐项结果和缺口见[频率说明](频率与时间窗.md)。

## 4. 检查与复现

在仓库根目录运行：

```bash
python3 资料研究/scripts/frequency_review.py
python3 资料研究/scripts/check_package.py
```

完整仓库副本不需要额外参数。本轮通过connector读取部分工作文件，检查时另传完整远端树清单`--source-manifest source-tree.json`，用以判断未下载原件的仓库路径是否存在；该临时清单不提交，也不等于读取了全部原件。

实际检查包括：

- 频率脚本运行成功；保存各输入文件的字节数及SHA-256、具体清单、未匹配项和统计口径。419题时差独立重算与旧数字一致，但没有据此认证旧来源标注。
- 10个时政示例的16条原句按指定原文匹配；真实设错或正确项按指定真题匹配，所用文本公开日早于对应实际笔试日。
- 32条表达的48处引文、19条词表修正的所引原句，按各自指定来源核对；任务与表达之间的引用有效。
- 原两张词表数量、记录顺序及原句、URL、出处、日期等来源字段保持；未校准的248条原记录行保持。规范称谓只改指定3条，2026材料溯源只改共享村落1条。
- 作文逐题重新读取，推荐材料区分政策原件、署名阐释和实践报道；推荐理由与历史题眼重合分列。
- 汇合阶段再次抽查8组各自的官方正文依据，内容支持所列政策关系；中试附件仅取得通知元数据、托育短文通过原站搜索索引读取等限制已保留在对应记录中。121条关系索引的名称、URL、顺序和原文件SHA-256一致，原文路径对照用户最新提交后的远端树。
- 包检查覆盖必要交付物、JSONL结构和计数、记录标识、相对链接及结构化来源路径。结果见[包校验](统计/包校验.json)。代码仅用Python标准库。

这些检查没有认证所有来源网页长期可达，没有把机构答案改称官方评分细则，也没有把引句匹配等同于全部语义正确。没有为本轮小范围资料改动运行不相关的整仓测试。

## 5. 尚存的数据缺口及使用边界

省考419条中，只有25条现有依据URL，22条题干摘要为空；旧来源名称有解析引用、多源压缩和日期身份混杂问题。74道国考与419道省考的目录候选关联仍需与具体断言区分。今后若要检验频率的边际作用，应先补足这些来源和时间证据，并事先固定规则、留出独立样本；本轮不据探索结果设置预测分值。

原始语料年度采样不均衡，不能用索引条目数直接比较年度政治强调。官方原发、转载平台与跨来源覆盖仍是不同计量。本轮没有重抓所有原文，也没有把现有索引当成完整新闻总体。

本轮保留原始raw、既有题本、原关系文件和个人进度，更新资料入口及明确错误。后续使用时，优先从本包已校准记录进入；其他旧条目继续按需要逐项核验。资料工作完成不表示教学已开始或考生已经掌握。

### 7.3 几项会实际改变调用方式的校准

- **W04旧空间更新**：明确与2024副省旧物价值存在核心命题重合，条件补充不冒充全新题眼。使用时需保留文化、情感、公共使用等维度，不能只写招商收入。
- **W01设施与服务**：从既有采样线索定向补入牡丹社区案例，实际核读辽宁省政府转载的辽宁日报报道，展示设施、专业机构、实际服务的连接。原采样所指住建部WPS未读到，未将另篇报道冒充原附件；新增记录只支持报道中的过程，不证明独立净效果。
- **W05产业升级**：鞋材研发与技术适配可以说明创造条件，但没有直接证明原先的劣势特征本身成为优势，不能独自承担完整的劣转优论证。
- **EX09监测预警**：原引句只直接证明信息传送给责任部门，归纳名收窄为信息传递衔接。写处置完成或整改闭环需要后续办理和复核证据。
- **EX03岗位保障**：特定偏远岗位补助不能扩成全市所有人员同额补助；质量、数量、效益的综合绩效不能缩为数量单指标。
- **EX14—16成效**：保留产值与利润、就业收入与保障制度、局部循环与零排放的区别；动作、机制与实际结果分别判断。
- **市场政治理论样本**：城市发展方向出现在待判断项中，只证明题面触及；答案未公开时不标为已经教会正确知识。传统产业升级的题干正面陈述只对实考一个选项提供局部支持，不换算为整题可解。

这些校准是本次逐条阅读和资料加工判断；示范不是完整标准答案，反例不是考生实际错误频率统计。

### 7.4 核验方法和实际界限
