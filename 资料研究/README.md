# 官方资料怎样支持时政与申论

本轮把官方文件、概念、会议、官媒阐释和实践材料整理成可调用的资料。范围为近五年国考市地级主线、副省级补充；当前完成的是资料工作，个人学习状态仍只记根目录进度。

## 直接使用

| 需要 | 入口 | 能得到什么 |
|---|---|---|
| 找值得积累的作文概念与素材 | [作文元主题与素材推荐](作文元主题与素材推荐.md) | 当前概念/命题组合、官方口径、可读材料、论证机制、与已考题眼重合及新切入 |
| 从叙事材料找概括、解释和措施 | [小题材料与表达](小题材料与表达.md) | 具体真题的现象—表达—机制—措施对照，正面做法与成效也在内 |
| 选择时政资料、理解频率和时间窗 | [频率与时间窗](频率与时间窗.md) | 准确命题和设错示例，固定序列统计，历史核对及其边界 |
| 查本轮实际完成及遗留问题 | [执行报告](执行报告.md) | 完成数量、核查方式、运行回执、尚未认证的内容 |
| 接续资料工作 | [SPEC](SPEC.md)、[PLAN](PLAN.md) | 用户目标、规则、交付标准和执行状态 |

- [关系索引](数据/关系索引.jsonl)：连接原121条出处记录，区分原文检索与可调用论证。
- [作文推荐](数据/作文推荐.jsonl)：当前推荐与历史证据分栏，保留来源和推断。

- [小题任务对照](数据/小题任务对照.jsonl)：题目、材料事实、合理表达及外部资料作用。

## 使用时的三个区分

1. **历史参照与当前推荐。**旧题帮助识别要完成的论证动作；当前推荐要另有官方材料和新切入依据。已考与未考都不是下一次出现概率的证明。
2. **原文与整理判断。**官方原句、题本事实、机构参考答案、我们的解释分别标明。相似案例可以帮助理解，但不能自动称作命题出处。
3. **能检索与可直接使用。**原库记录很多；进入本轮校准入口的条目才经过所声明范围的语义检查。完整索引不意味着全部条目已认证。

作文可以根据题干要求联系实际；限定材料小题的外部资料用于理解、归类和选择手段，不能带入题本没有的事实。推荐优先级表达积累价值，不是预测。
