# 官方资料支持时政与申论：工作规格 v2

生效：2026-11-16。依据：用户本轮授权——先写 spec 与 plan 并推送，再按 plan 完成资料工作并更新远端。起点：rush/master 9fa62caabe8bb48e20e2ecf71d2a0177491b32cd。

v2追加授权（同日）：用户在市场冲刺资料比较后要求“更新标准后开始继续做，并且完成计划”。首版成果已在`e4ec5954a1ee9378b404c51aff6ad42c0a47da10`完成；本次以该版本为基线，按第8节完成有限增补并推送。下列原要求继续有效，第8节补充资料可用性的验收口径。

## 1. 目标与使用范围

把现有官方文件、讲话、会议目录、官媒文章、实践案例和真题，整理为能够支持时政辨析、作文论证、概括、分析和对策的资料。主样本为2022—2026国考市地级，副省级独立补充；行政执法和省考仅在明确标注的比较中使用。

**必须交付作文推荐。**依据历年题目实际要求、官方持续强调的认识与方法、近期经核实的政策概念和官媒论证，推荐值得积累的元主题、概念和素材。允许有依据的推测和迁移判断，必须说明推断理由与边界；不要求证明某个题眼直接出自某篇文章才可推荐。推荐优先级表示材料的解释力、可迁移性与可用程度，不表示下一次考试概率。

**用户补充：避免把已考题眼直接变成推荐清单。**历史真题只用于辨认任务要求、关系机制及材料用法，不以“过去考过”给推荐加分。推荐表须分别列出历史任务证据、近期官方强调、与近五年市地/副省题眼的重合程度、新切入角度。近期直接考过的表述放在参照位置，主推荐呈现有独立官方依据的新概念、新场景或新组合。既不承诺“考过不会再考”，也不把“尚未考到”解释为更可能考；元主题的迁移价值与具体题眼的重复风险分开讨论。

本轮完成资料加工与研究支持，不开展授课、测试考生或改写个人掌握状态。既有学习计划可以链接这些成果，但不因资料完成而标记课程完成。

执行中用户追加了`b794003cd713910d6b9c5bb2281a71a66840fbad`中的`analysis/kaocha.py`及三类题考察报告作为参考。读取其结论与实现，吸收可支持的资料处理建议；统计口径及确定性判断须与原始证据核对，不直接继承。该参考及同提交的原文文件名调整保留，实施提交基于此后最新远端，不覆盖并发工作。

## 2. 三类内容分别回答什么

| 用途 | 直接产物 | 必须保留的信息 |
|---|---|---|
| 时政 | 准确命题及设错对照 | 主体、对象、范围、条件、成组关系、出处和版本 |
| 作文 | 元主题、论证命题及相应素材推荐 | 题干要求、关系机制、成立条件、官方表述、事实及其证明作用 |
| 概括、分析、对策 | 现象到表达、解释和措施的对照 | 材料证据、表达角色、因果或互动、实施主体和条件 |

议题档案保留为纵向入口；关系与论证、现象与表达、措施与工具、时政命题与设错保留横向入口。多对多标注，不把跨议题工具搬进唯一专题，不把所有题都预判为两端关系。

## 3. 事实、解释与推荐的标记

每条可直接使用的记录须区分：原文说了什么、题本给了什么、机构答案怎样写、整理者怎样解释。引文逐字相符只证明出处匹配，不认证语义、案例映射、命题来源或得分。

来源关联分为：题本直接点名；具体事实细节对应的原型候选；同议题或同机制的类比阅读。不得用后两项冒充已证实取材。推荐可以使用第三项，但须解释它帮助理解或论证什么。

词条校准至少检查词义、原句立场（肯定、批评、禁止、条件允许、描述）、表达角色（问题、原因、做法、机制、成效、措施）、对象与适用条件。负面语境中的台账、考核、关停等可作为边界案例；不能自动生成建议。

提法关系区分正式更名/明确替代、上下位、并行政策、目标或重点变化、重组表达和待核。不同年份用了不同词，不足以认定旧词错误。历史题按当时可公开获得的依据分析。

## 4. 首版交付物

1. **作文元主题与素材推荐**：6—8组推荐，覆盖关系机制与实践价值主题；每组说明当前建议积累的命题/概念组合、推荐理由、历史任务参照、与已考题眼的重合程度、新切入、官方概念及口径、至少两项可阅读素材、论证机制及使用限度。近期概念与历年长期主题分开标注。至少一项素材给出可核查的公开官方URL；同时链接仓库已有材料。排序不使用虚构分数，不因考过或没考过而赋予未经验证的概率权重。
2. **作文题任务索引**：独立读取近五年市地/副省10道作文，分别记录文体、题材范围、实际论证动作、条件与材料用途。分类是本次判断，不复用“全关系型”的预设。
3. **关系检索入口**：覆盖原121条关系/原则记录，保留原出处；原文索引与经过论证校准的推荐条目分开。不能把121条都称为可套用模板。
4. **小题支持包**：至少8个具体题目对照，覆盖概括、解释或原因、互动或评价、问题与对策、应用文中的尺度转换；另提供至少24条经过语义校准的表达/工具记录，含正面做法、机制、成效及负面边界。原两张词表已发现的明确错误就地修正，保留修正说明。
5. **时政资料支持包**：修正已发现的提法关系错误；给出准确命题、条件和真实设错的示例，以及可复算的序列覆盖、频率描述和历史核对结果。
6. **执行报告和入口**：记录实际完成数、复核范围、未解决的数据缺口、运行方式；更新根入口与交接，让后续模型能直接使用成果。

最低条数用于保证覆盖，不把凑数当质量。推荐材料须能具体说明用途，重复转载不充作独立素材。

## 5. 频率与历史核对的边界

固定统计总体：求是每期署名文章目录、政治局集体学习目录；年度日历仅报告覆盖缺口，完整性不足时不拿它排名。原讲话、首次公开、重新刊发分别处理；缺数据不当零频次；2026未完年与历史同期对比，来源分别报告。

脚本使用公开、可解释的分类和匹配规则，输出未匹配项，保存输入摘要与限制。标题命中明确标为标题命中，不能称全文强调强度；主题关联不能称为答题知识覆盖。

历史核对使用实际笔试日，区分题干指向文件、答题必要依据和解析引用；多依据不能压成一份最近文件。419省考表的标注未经全部认证，主文必须报告其局限。可交付探索性关联核对，但不得包装成经独立验证的预测回测。只有在来源与时间可用、能实际对照必要知识的子样本上，才比较“基础文件与近期文件”与“增加频率线索”的差异。不为得到权重而填补未知值。

## 6. 验收与完成定义

- 交付文件在仓库可读，跨文件链接存在；JSONL可解析，标识与来源可回查。
- 作文推荐明确落实用户新增要求，包含推荐的元主题、热门概念、官方口径和具体材料；不能只交付“不预测”的限制说明。
- 抽查每组作文至少一条原始官方来源；事实、原话、我们的归纳标清；语义校准条目不以逐字匹配代替解释核对。
- 统计脚本能够在现有仓库材料上运行；关键计数与独立复算一致；未获支持的结论不写进推荐理由。
- 只检查与本次风险有关的内容：路径与结构、已修正错误、关键计数、来源及推断关系，不扩展整仓测试。
- 提交到master，推送前复查远端head，保留其他模型已提交的更改；不得覆盖并发工作。

## 7. 不在本轮范围内

不重做所有原始采集、不重判所有历史机构答案、不建立自动评分系统、不安排学习日程、不估计提分、不把公开资料广度当学习效果。原始raw不搬移不改写；未进入本次可用索引的旧条目继续保留为待逐项核查资料。

## 8. v2：市场对照后的加工与评价标准

### 8.1 四种结论分别证明

1. **资料准确**：来源和日期可回查，转述保留主体、对象、范围、条件；引文与归纳分清。
2. **题目适用**：明确能解释哪个关系、支持哪个判断或措施，并给出不能使用的情境。
3. **作答效果**：需另有实际作答与可靠评价证据。本次不测试考生，不把材料加工完成记为成绩或掌握提升。
4. **预测能力**：需可核考前版本、完整候选范围和一致判据。现有八组是在阅读历史真题后形成的，旧题适配检查不能称为独立预测回测。

推荐顺序表示目前的采集、加工与阅读判断。没有等容量独立比较，不声称比机构更准；与机构相同的官方来源或热点，也不自动证明选择更优。频率只提供完整序列上的线索，仍不设置未经验证的概率权重。

### 8.2 作文与小题必须落到可判定的使用规则

- **作文8组逐组加工**：具体判断及必要条件、真实材料的作用过程、整理者论证示范、至少一个拒用情境。示范是我们的写作加工，不能标为官方原话、真题标准答案或预测范文。现有素材足以支持时不重复扩采。
- **旧题重合分三层**：核心命题相同、论证机制相近、仅题材或概念相邻。列清对象、关系方向和条件有何差别；换场景或换词不自动算新命题。重合只用于去重与适配，不据此估计重考概率。
- **小题32条逐条补齐**：使用该表达所需的材料证据、证据不足时的写法或拒用条件。至少8组正反对照，覆盖做法、机制、成效、问题、原因或措施；错误例须注明是整理者编制。定性强度不得超过题本证据。
- 官媒原报道中存在、题本删去的处理结果不能补回限定材料答案。外部资料可帮助理解和归类，不能凭来源权威跳过题本证据。

### 8.3 时政交付到具体判断

新增24条辨析卡，覆盖8份经过正文核验的官方依据；以截至2026-11-16已公开的近期重要内容为主，保留必要基础原则。每条说明：正确命题、主体/对象/范围/条件、易错改写、改错位置及原因、来源与日期、能支持的选项判断。

易错改写统一标为整理者编制的辨析示例；旧10个真实题例保留原身份。区分“碰到同一文件”“涉及同一断言”“资料明确提供正确性”“足以解出整题”。仅在待判断选项中出现某句而答案不可见，不能算已提供正确知识；新旧词同时出现不构成替换或失效。

### 8.4 市场比较保留分母与产品范围

保存本轮已读的5组公开样本：2组申论热点集合、2套政治理论模拟题、1组仅部分公开的热点内容。完整集合逐项记录，保留未匹配项、原始题号/条目和来源URL。机构全量产品与某个公开集合、全卷热点与纯作文预测、题面与答案解析分开标注；未公开部分不按零命中处理。

作文分别判断领域关联、局部机制、核心命题及限制条件、实际可用材料；时政分别判断来源、具体断言和答题充分性。考后“覆盖”宣传只作为主张记录，没有完整考前范围时不计算准确率。页面自报日期与考前存档证据分开，不把同机构重叠材料当独立实验。

### 8.5 本轮完成条件

八组作文与32条小题达到上述使用规则，24条时政卡及8份依据核验完成，市场完整/部分样本及逐项对照可回查；文档与结构化数据对应，现有ID和来源保留。更新导航、执行报告和交接，运行针对新增字段、引用、计数与边界的检查，基于最新远端正常提交推送。

未来考试发生后的预测验证、学习效果验证、419道省考全部来源认证仍属独立后续事项，不为宣称本轮完成而填造结果。本轮完成的是已经授权且当前可以交付的资料加工。
