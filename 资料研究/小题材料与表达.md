# 小题材料与表达：从现象到解释、归纳和措施

版本：v2，2026-11-16。依据[工作规格](SPEC.md)。本包用于整理资料和支持后续解题，不是完整课程，也不记录考生掌握情况。

**官方材料最有用的部分，是帮助读懂事情、准确命名、解释作用机制，并找到符合条件的处理办法。**小题最终写什么，由题干要求和给定材料决定。只有“这是乡村振兴／数字治理”的议题判断，尚不能回答“怎样做到”“为什么成功”“问题在哪里”“应该怎么办”。

本资料包包含 **10个任务对照、32条表达与工具记录**。任务中9个来自2024—2026国考市地卷，1个副省评价题独立补充；这是选例支持包，不是各题型频率统计。v2为32条逐一补齐可观察的证据门槛、主客体与范围、证据不足时的处理，并提供 **14组局部正反改写对照**。原有两张词表共267条，首版仅精校其中19条，其余248条没有因本次处理获得语义认证。

## 3. 从现象到表达，要通过哪些判断

### 3.1 来源正确与题目适用分别核对

第一步核对**资料准确性**：这句话是否出现在所引来源，谁对什么事说的，是肯定、批评、禁止还是条件允许，是否保留时间、对象和限定。第二步核对**题目适用性**：题干要求概括什么、解释什么或建议什么，限定哪些材料，拟用表达所需的事实是否真的出现在该范围内。前一步通过，不能替代后一步。

例如，通报对大量台账、照片、截图增加基层负担的批评有明确出处，但共享村落题没有这类报送事实，不能借该通报把召开推进会直接写成形式主义。牡丹社区调查需求、配置服务的官方案例可帮助提出适配建议，案例中的2800多份问卷不能变成S市文化空间题已经发生的事实。原型报道中被题本删去的处罚、问责和后续效果，也不能补回答案。

每次判断保留一个最小事实单位：**谁，对什么对象，做了什么或发生了什么，在何种范围和条件下，有何已知结果。**若题本只是引述某人的看法而未给足事实，需忠实转述时保留评价主体；不能把人物意见无条件扩大为所有主体的事实。以下规则用于资料筛选与表达校准，不是评分细则。

| 表达角色 | 至少需要什么证据 | 不满足时怎样处理 |
|---|---|---|
| 做法 | 主体实际采取的动作、对象和必要环节 | 只有目标写目标，只有计划写计划；不补成已经实施 |
| 机制或互动 | 动作之间的连接，如需求进入采购、建议进入决策、信息传给责任部门 | 只见双方到场就写双方参与；未见后续处理不写完整闭环 |
| 成效 | 已发生的变化、受益主体和指标含义 | “拟、将、能”不直接写成已实现；产值不改成利润，局部结果不扩大为全面改善 |
| 问题 | 具体缺口、不当行为或与任务要求不符的事实，保留评价所依赖的限定 | 材料没提制度，不等于制度缺失；只有多部门参与，不定性多头管理 |
| 原因或评价 | 能解释结果的过程线索，或不同条件下的比较依据 | 只有先后出现不自动认定因果；不把一个因素写成唯一原因，也不只按新旧名称定好坏 |
| 措施 | 已知障碍、可实施或协调的主体、动作和对象，以及题设条件 | 可提出材料未实施但适配的建议，须标为建议；不虚构已经发生，不越过角色或取消必要约束 |
| 应用文中的推广 | 题干允许总结经验，且分清可推广机制与个案参数 | 保留岗位、人群和资源条件；县域金额、名额不直接变成全市统一指标 |

“成立条件”字段现在写明各条所需的事实组合；“不可据此推出”记录拒用的结论；新增“主客体与范围”和“证据不足时写法”分别防止对象扩张、指导退回较窄事实。复合表述只满足一部分时，保留已获支持的部分，不因同属一个议题就补齐其余内容。例如只有监测信息转送，EX09支持“与责任部门信息传递相衔接”，尚不支持“完成整改闭环”。

前13组使用题本情境，最后1组专门演示官方范例迁移的边界。有效迁移的对象是处理问题的机制，进入限定材料答案的事实仍须在题本中成立。对策可以有合理推导，但“可建议开展”与“已经完成”须分开。

## 4. 四个例子说明资料应加工到哪一步

### 4.1 基层卫生人才：需要把故事转成适用于全市的安排

2024市地第3题材料写了某院绩效改革、偏远岗位补助、富余编制周转、人才培训和县管乡用等措施。题目要求的是全市实施意见，因此资料整理应留下“面向哪些人、用什么办法、解决哪种问题”，而不是只留下人物姓名和故事。

例如，“干多干少一样”对应激励不足；材料中的服务质量、数量、效益考核和待遇安排提供具体改进方法。可归纳为完善基层人才激励与保障，但不能把某类岗位每年2万元补助扩成所有医务人员统一待遇。编制周转也须保留“利用富余编制、用于紧缺专业”这些条件。（数据：SQ03、EX03—EX04。）

现有[2024溯源记录](../资料采集/01-材料溯源/2024.jsonl)把部分细节对到2021年《健康报》报道，题本末尾又接入二十大报告的表述。这个具体候选显示：旧实践可以放入新的政策语境。不能据后接文件，反推此前的报道一定由它向下衍生；原型关联的证据等级也没有因此提高。

### 4.2 政企治水：需要保存动作之间的连接

2025市地第2题里，政府公开需求并购买服务，企业调查和研发；企业综合专家意见提出建议，政府论证后组织实施；平台监测发现异常，再把信息传给责任部门。后续还有试用、推广和规程制定。

“政企协同”“数字赋能”可以作为概括，但它们必须能展开为这些关系。资料加工应保存需求如何提出、能力如何接入、建议如何进入决策、信息如何触发处理；只有“政府做了几件事、企业做了几件事”的并列摘录还不够。（数据：SQ05、EX07—EX09。）

### 4.3 农业“三效”：需要保存结果与受益主体

2026市地第2题已经规定三类。全国销售、产值增加和带动周边产品销售可说明经济结果；本地居民就业与获得收入可说明社会结果；甲鱼吃螺、排泄物肥田和沼液利用可说明生态作用。不能只记“产学研合作”“建立公司”这些做法名词，期待它们自动成为成效。

同一做法可以同时影响企业用工和居民收入。整理时分别记录具体结果，答题时再按题目要求使用，不把整个案例排他地归入一个专题。（数据：SQ08、EX14—EX16。）

### 4.4 共享村落：需要把概括的强度限制在证据以内

2026市地第4题足以支持道路、污水垃圾、燃气等配套不足，跨部门协调不畅，经营规则不足，产业衔接和履约约束薄弱等判断。“一个部门说了不算”不自动等于多头管理；开会宣传与建设缺口并存，也不足以单独证明形式主义。

因此首版已修正[2026溯源记录](../资料采集/01-材料溯源/2026.jsonl)该条的“纠偏类型”，将先前值保存在“定性修订说明”内。原报道仍是低置信候选，逐字状态C保持，不借此提高来源可信度。

措施也要对准问题：有人统筹、责任与办理流程清楚，是协调建议的实质；“建立专班”只是可选形式。对合同未约束违约情形，可提出细化义务和违约处理；对设施不足，应安排相应配套。不能用台账、考核、宣传替代这些具体工作，更不能自行改变题本的租期等条件。（数据：SQ09、EX17—EX19、EX25、EX30。）

## 5. 首版怎样修正词表

原[问题定性词表](../资料采集/04-官方案例与通报/问题定性词表.jsonl)143条、[整改手段词表](../资料采集/04-官方案例与通报/整改手段词表.jsonl)124条，数量均保持。首版分别修正7条和12条；v2使用其核读结果补使用规则，没有扩大原词表精校数量。**错误的“含义”字段已就地替换**，不是只在末尾补一句提醒；旧定义和理由保留在修正说明与校准记录中。

| 错误类型 | 已处理条目 | 校准后的用法 |
|---|---|---|
| 相同词形、不同含义 | 红线、媒体、多头 | 建筑区划界线不是原则底线；智媒体系统不是媒体监督；多头重复申报不是行政多头管理 |
| 负例中的工具被当作建议 | 台账、排名、考核、关停、清单、投入 | 记录批评或禁止立场，保留对象、目的与方式，不自动推荐工具 |
| 中性名称被当作问题 | 管护责任、通报、占补平衡、增减挂钩 | 把制度或责任名称，与未落实、违规、强制等谓语分开 |
| 名词对象被当作行动 | 思想根源、顽瘴痼疾、系统领域 | 分别是分析对象、问题名称、行动范围，独立出现不构成措施 |
| 关键限定被截掉 | 留痕，以及涉及排名、考核的负例 | 保留“过度”、不当目标、变相强制等决定性质的限定 |

同一个词可同时出现在问题表与手段表中，校准记录按“文件＋词”定位，因此表中列举的词数不直接等于19条。官方原句、出处、日期、URL、出现于哪些通报和原逐字状态全部保持原值；只修改定义并补立场、表达角色、边界和修订说明。

“台账有负面案例”不意味着任何台账都错误。“考核有负面案例”也不否定基层医疗题中的合理绩效激励。资料要说明**什么主体在什么目的下怎样使用工具、产生什么后果**，而非建立一张永远正确或永远错误的词清单。

## 6. 32条表达记录保留什么

| 字段 | 用途 |
|---|---|
| 归纳表述、表达角色 | 区分问题、原因、做法、机制、成效、措施、工具边界或术语辨义 |
| 检索现象 | 从题本的叙事事实反向查找，不必先猜议题 |
| 材料证据 | 文件、题号或案例定位、原句、来源身份；官方资料另附公开URL |
| 原文立场 | 肯定、批评、禁止、条件允许或描述，避免取反 |
| 整理者解释、成立条件、不可据此推出 | 区分解释、可观察的证据门槛与拒用条件，不以议题标签代替判断 |
| 主客体与范围 | 保留谁对什么对象采取行动，哪些人、地域、时间和参数属于该材料 |
| 证据不足时写法 | 指明只有部分线索时应退回的事实表述，或不能使用的结论 |
| 措施建议 | 如涉及建议，说明主体、动作、对象和必要条件；与原文分开 |
| 关联议题、对应任务 | 多对多索引，不移动原素材，不把表达并入唯一议题 |
| 整理者改写对照 | 14条有此字段：性质、适用任务、示范用途、材料支持的写法、越界写法、为什么越界 |

EX01—EX20主要由选定真题提炼，EX21—EX24提供官方经验范例，EX25—EX32处理语义和工具边界。不同记录的用途不同，不能把32条都称作可直接套用的答案模板。

官方经验范例来自住建部[《城市更新典型案例经验做法（第一批）》附件](https://www.mohurd.gov.cn/file/2024/20240130/11f2e8ed-fb65-432b-9496-d498bf654c79.wps)，包含红育坡与牡丹社区的具体做法。它们支持同机制类比阅读，不是对应真题取材来源的证据。例如需求清单用于回应居民需求，和违规要求清单外备案材料，虽然都有“清单”二字，实际机制和评价完全不同。

## 7. 后续收集资料的选择依据

| 资料类型 | 值得提取什么 | 不宜做什么 |
|---|---|---|
| 政策文件与会议依据 | 目标、概念、原则、约束、成组关系 | 把所有题都改写成文件宣传 |
| 部委实施意见与办理规范 | 主体、对象、程序、激励、协同、保障安排 | 只有加强、完善、重视等空方向词 |
| 官方典型案例 | 做法怎样产生效果、在何种条件下可推广 | 只存案例标题、荣誉和漂亮结尾 |
| 官媒调查与通讯 | 人物诉求、问题环节、行动过程、未解决障碍 | 只取正面评价，删掉冲突和边界 |
| 官媒评论 | 判断依据、因果、条件、反例和关系展开 | 把评论作者观点升级为官方评分标准 |
| 问题通报及整改 | 什么行为为什么不当、怎样纠偏、防止纠偏过度 | 见到名词就加入整改工具表 |
| 真题与参考答案 | 核对资料能否支持题目动作和材料证据 | 将机构答案的字词、条数当作唯一评分规则 |

小题中外部知识的主要作用是帮助理解、命名、组织和判断措施是否适配；写入答案的事实与判断仍须接受题干和材料约束。这既允许必要推理，也避免把熟悉的政策议题强套给材料。

用户执行中追加的[三类题考察](../analysis/考察-三类题与官方话语-2026-11-16.md)进一步提示：应优先从实施类文件的“主要措施”和官方经验做法中收集行动机制，督查通报主要补充问题识别与工具边界。机构答案与词表的字面命中只能作为选择资料的辅助观察，不能证明答案的实际语源，也不能据低命中判断通报没有价值。

**原型报道与题本的删改应另留记录。**原型全文帮助理解现实处置，题本保留的事实决定该题可据以判断的范围；若采集记录指出原稿中的问责、罚款或后续效果被删去，须逐项比对后确认，不能把删去内容直接补回答案。反过来，题本新增的条件也须单独识别。删改痕迹字段的关键词统计不等于逐案证明，更不直接证明命题人的意图。

## 8. 已做检查与实际限度

首版核对了10个任务的题干、所引用材料及分析；32条表达记录均保留证据，所列48处引用按指定文件检查，而非跨整个原文目录碰运气匹配。19条词表修正的原句也在各自明确标注的原文中核对；正文语义校准关注词义、立场、对象、作用和边界。引句比对允许去空白和统一中英文引号，不改写原句。

v2保留32个表达ID、10个任务ID和全部48处原引句及来源，逐条核对证据门槛、主客体、范围与拒用条件；14组改写引用既有任务，未增新题。部分门槛需结合所标材料的上下文，例如EX10认定已实现收益还须看实际分红，不能只靠“能提高”的预期句。EX21—EX24明确为官方案例类比，EX25—EX32主要检验工具和术语边界；它们不因出处正确而自动成为题本事实。

这些检查支持“资料可回查、表达有条件地适用”的判断，尚不证明考生实际作答效果、唯一得分词或提分幅度。14组越界句是整理者编制的辨界示例，不能当真实考生错误频率。

原267条总数保持，未校准248条保持原内容；本轮没有重判全部词表、验证所有来源网页、重建所有命题来源，也没有取得官方评分细则。题本与原型候选、官方原话与整理者解释、正面范例与通用建议，均在数据中分开。后续使用旧词条时，仍应按本包的语义规则逐项核实。
