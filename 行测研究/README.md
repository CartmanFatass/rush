## 一、目前能确认的考情变化

1. **数量主样本为数学运算。**10卷校正后共有125个数量题位，按同年qid去重为101道，未见独立“数列填下一项”的数字推理。2027大纲仍列数字推理与数学运算，故不能推断未来绝不考数字推理。生产、销售等差变化仍属需要掌握的数学运算。[2027大纲公开转载](https://jy.slu.edu.cn/2026/1014/c557a58735/page.htm)
2. **2025、2026判断推理为35题。**图形10、定义10、类比5、逻辑10；旧的“四类各10”不能直接沿用。这个结果与近期机构回顾一致。[华图2027大纲解读中的历史题量](https://m.sd.huatu.com/2026/1014/1624556.html)
3. **2026地市逻辑的独立部分有变化。**按题意划分为支持类3、削弱类1、翻译推理1，另有一段材料带5题的约束分析。因此旧的“5论证＋5分析”概括不再精确。
4. **2026副省实际出现平行结构题。**原第115题要求匹配论证形式，题干与正确项都采用“肯定后件推出前件”的形式；识别结构与判断推理是否有效是不同任务。
5. **图推、资料的基础知识框架继续适用。**近期真题提供了更多需要联合处理的条件：图推中观察白区、顶点、局部属性，样式运算再旋转，视图加颜色和总数；资料中基期还原、累计转当期、混合权重、图表匹配。这是对已见试题的描述，不是未来频率预测。

第3、4项以[2026地市题本](../行测/2026国考行测（地市级）.md)、[2026副省题本](../行测/2026国考行测（副省级）.md)及Xtest原序号交叉核对为依据。详细qid、原题号与主目录序号见专项文档和核验记录。

## 二、四部分分别需要补到什么程度

### 数量关系：把题型与方法触发条件连接起来

基础教辅已覆盖方程、比例、工程、行程、计数、几何等。需要补的是“遇到哪种条件，先减少哪一步运算”：精确人数比例先看整数倍数，同一随机试验的概率比先约共同分母，多产品生产先找产能下界再构造可行安排。

近年复杂限制也要单列：每一步都满足的前缀条件、分段价格的连续性、匀加速与匀速区间、日期同余、最值是否可达到。只会给题目贴“工程题”或“排列组合题”标签，还不足以选择实际解法。

### 数值计算：先判断需要算什么，再控制精度

增长、比重、平均数可由少数基本关系相互推导。速算应区分精确变形、大小比较与数值近似；约分、同分母合并、移项比较可以先消除运算，截位和分数近似才需要误差判断。

现有九课规范已经要求最小精度和基期权重。本次用具体例题补齐执行依据，并给出“增长量不能只比现期量×增长率”的反例。所有方法都要说明单位、统计口径、正负和选项间距；没有统一适用于所有题目的误差许可。

### 图形推理：观察对象、操作顺序与多个约束

平移、旋转、对称、点线面、六面体等基础目录完整。新补充强调：看整体无规律时，是否应看顶点、最大面、封闭白区或某类交点；总数相同是否还需按形状或位置筛选；样式运算与旋转按什么顺序执行。

空间题要同时满足面关系、图案朝向、公共边或顶点、颜色、数量等条件。截面来自同一个平面，三视图是投影；相邻只是折叠的初筛，体块数量守恒只是拼合的初筛。

### 逻辑关系：按任务选择证明方式

必然性推理需要正确的方向、否定、量词和且或关系；约束题需要有效表示与合法安排；论证评价要找证据到结论的缺口；平行结构要保持形式；类比要保持关系、方向、角色与层级。

“可能”只需一个合法安排，“一定”要覆盖全部可能；必要假设和充分桥梁不能混用；另有其他原因不能自动否定原原因。共材料组题的基础推论可以复用，各小题新增假设则须撤销。

## 三、现有材料的覆盖与真实缺口

[教辅登记表](../教辅/行测/manifest.md)共31条：20条方法讲义或文章全文、11条书目/目录/商品介绍。其中数量7份全文、图推7份全文、资料分析6份全文。部分综合PDF的文字版跨多个模块，逻辑内容也包含在图推目录下，不能只按文件夹判断。

正文基础仍然可用；新版图书目录只能证明章节覆盖，不能据此声称仓库已获得或读过整本书。此次补充优先解决以下内容：

| 缺口 | 本次形成的内容 | 后续使用要求 |
|---|---|---|
| 方法名与题干条件脱节 | 每类的识别信号、普通法、快捷法和适用边界 | 先解释模型，再选方法；不承诺统一秒杀时间 |
| 近年混合题实例不足 | 整数采购、概率比、资源调配、复合图形、空间多条件、逻辑组题 | 保留真实条件及原图，不把简化版冒充原题 |
| 速算口诀过度泛化 | 增长量反例、基期权重、误差式、最近项边界 | 根据选项判定近似是否足够 |
| 形式逻辑与论证混用 | 条件/量词规则、必要充分区分、因果边界 | 统计倾向不能直接改成充分条件 |
| 文字抽取丢公式与图像 | 原图相对链接、必要的公式重写、核验范围标注 | 精确题解回到完整图和表达式 |
| 主目录标签与原题号不完全可靠 | qid与题号映射、错放记录、按题意分类 | 题型统计不直接依赖导出标签 |

## 四、与既有教学的关系

资料分析继续沿用[九课教学规范](../行测/资料分析专项/学习计划与教学规范.md)；根目录[进度](../进度.md)仍是唯一个人记录。本轮交付是研究材料，没有据此认定个人掌握程度、完成练习或通过节点，也没有重排学习日程。

专项文档包含已解真题，尤其是2025—2026代表题。讲解、资料准备与学生实际作答应分开记录；已完整看过答案的题不能再当作未见过的阶段整组样本。研究结论、机构说法和整理者反例分别标明，样本频率不替代效果验证。
