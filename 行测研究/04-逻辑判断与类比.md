更新日期：2026-11-16。研究依据为仓库内 2022—2026 年国考副省级、地市级真题，两份华图判断推理讲义，以及截至本日期检索到的机构教学与考情资料。题量与题型以实际题目为准，方法按适用条件和反例检验。

## 一、研究范围与考情结论

- 逐题审阅了下表 10 卷中的逻辑题干、选项，以及地市每年的共用材料；统计时按题意调整被错误标注题目的归类，共 **100 个逻辑题位、87 个不同 qid**。同题跨卷重复，不能当作独立样本。

- **2025、2026 判断推理题量为 35：图推 10、定义 10、类比 5、逻辑 10。** 2022—2024 类比仍为 10，判断总计 40。旧的“四类各 10 题”表不能直接用于现在。近期机构考后分析与仓库真题相符。

## 二、逻辑判断的方法框架

### 1. 翻译与必然性推理：先确定方向，再压缩文字

适用：题干给出的条件被当作真，询问一定能推出、不能推出、补哪个条件足以推出等。动作是给反复出现的事实命名，保留“且／或／否定／至少／至多”，然后连接条件链。

| 形式 | 正确含义／等价式 | 常见误用 |
|---|---|---|
| 若 P 则 Q；P 是 Q 的充分条件 | P→Q；Q 是 P 的必要条件 | 见到 Q 就倒推 P |
| 只有 P 才 Q；P 是 Q 的必要条件 | Q→P | 按句子先后机械写 P→Q |
| P→Q 的逆否 | ¬Q→¬P | 把 ¬P→¬Q 当作逆否 |
| P→Q 的否定／矛盾命题 | P∧¬Q | 与“否命题”¬P→¬Q 混为一谈 |
| 除非 P，否则 Q | ¬P→Q，等价于 P∨Q | 误认成 P→Q；擅自认为 P、Q 互斥 |
| P 或 Q | 至少一真，允许都真；¬P→Q | 肯定 P 后否定 Q |
| 要么 P 要么 Q | 恰好一真 | 把所有自然语言“或者”都按互斥解释 |
| 并非（P 且 Q） | ¬(P∧Q)＝¬P∨¬Q | 同时否定两个分句，误写成 ¬P∧¬Q |
| 并非（P 或 Q） | ¬(P∨Q)＝¬P∧¬Q | 只否定其中一个分句 |
| P、Q 至多一个 | ¬(P∧Q)，允许都假 | 当作恰好一个 |
| 并非所有 S 都是 P | 有的 S 不是 P | 误写成所有 S 都不是 P |
| 有的 S 是 P | 至少一个；可能全部 | 推出“有的 S 不是 P”或“并非所有 S 是 P” |

还须保留三个边界：

1. 在现代量词解释下，`所有 S 都 P` 只有在已知 S 非空时，才能推出 `有的 S 是 P`。不要直接套带存在预设的传统对当方阵。
2. 两个“有的”不一定是同一对象：有的 A 是 B、有的 B 是 C，不保证有的 A 是 C。反例可用不同的 B 个体构造。
3. 条件箭头的传递适用于题设条件；日常因果、统计相关、提高概率不是自动的充分条件。不能把“可能导致”擅自变成“一定导致”。

加速方式：优先圈只有、必须、除非、不、并且、至少；对同一命题统一命名；找选项真正询问的两端，压缩其余背景。看到肯后、否前时，用一个反例检查结论是否必然。条件链方法可参照[华图：连锁推理之假言命题](https://gs.huatu.com/2025/1022/1838561.html)，应用前须先核方向。

### 2. 约束分析／朴素逻辑：表示对象、占位与约束

主要题型：人员与岗位匹配、日期与顺序、选若干人、分组与兼任、环形座位、真假话。它们共同的问题是“哪些安排满足全部条件”，但应选合适表示：

- 一对一对应、每行每列唯一：二维表，记录确定值与禁止值。
- 先后与相邻：顺序链、绑定块、空位；相邻不等于先后。
- 选择／不选择：布尔量 + 人数总量。人数和互斥条件经常比逐个枚举更快。
- 分组／兼任：先写每组容量和每人可出现次数，再写共组或不能共组。不能擅自把“至少参加一次”理解为“只参加一次”。
- 真假话：先寻找真正互为矛盾的两句；恰有一真时，矛盾对已占用唯一真话，其他句子都假。仅仅内容相反未必构成矛盾对。

优先从 **约束最紧、出现最频繁、可结合数量锁定的条件** 切入。遇到二分条件，可以分支；每个分支立即传播约束，发现矛盾就停止。

共材料五题要分开“基础条件”与“小题新增条件”。基础推论可复用，小题假设答完即撤销；不能把第 107 题的假设带入第 108 题。

| 问法 | 需要证明什么 | 省时做法 |
|---|---|---|
| 可能 | 至少有一个合法安排 | 给出一个满足全部条件的见证 |
| 一定 | 每个合法安排都满足 | 直接推导；或假设其否定造成矛盾 |
| 不可能 | 没有合法安排 | 代入候选并找到违反的条件 |
| 最多／最少 | 界限 + 可实现该界限的安排 | 只有上下界，没有可行安排，还未完成证明 |

### 3. 加强、削弱：分析“证据为什么支持结论”

实际题型以因果研究、调查抽样、类比外推、方案可行性、比较选择为主。统一动作：明确结论主体、范围、时间与强弱；区分背景和证据；指出从证据到结论缺少什么；再比较选项对这一步的影响。

| 论证结构 | 检查点 | 有效的补充／削弱方向 |
|---|---|---|
| 两件事相关，因此 A 导致 B | 时间先后、共同原因、组间差异、测量是否一致 | 可比对照、机制支持；混杂、反向因果、样本选择 |
| 样本显示 X，因此总体 X | 谁被抽到、是否自选、样本覆盖 | 代表性；不是只看样本大不大 |
| 动物／局部／短期成立，推人类／整体／长期 | 外推对象与尺度是否相容 | 关键机制相似；对象或时间差异 |
| 措施 M 可达目标 G | 机制、实施条件、成本、副作用、替代措施 | 能实施且确实作用于目标；执行失败或净效果抵消 |
| A 比 B 更好 | 比较标准、共同条件、相对变化 | 补充相对优势；只说 A 好但不比较通常不足 |

比较削弱力度时，先核相关性、对象一致性、结论强度和选项所证明的程度，再辨认手法。不同题干不存在通用的固定排序。[华图对他因与无关项的辨析](https://ah.huatu.com/2025/0928/3122519.html)提供了分类线索，仍须结合当前论证判断，不能仅凭“也”等词语定性。具体边界如下：

- “还有其他原因 C”不自动削弱 A 的作用；若 C 能解释题中差异、与 A 共变并替代原解释，或原结论说 A 是唯一／主要原因，才可能切中论证。
- “倒因为果”也非万能最强；双向作用可能并存。需看选项是否真正破坏当前方向的证据。
- “无 A 有 B”否定 A 的必要性，“有 A 无 B”否定 A 的充分性；都不自动否定 A 对 B 的概率影响。
- 单个反例足以推翻“所有／必然”，未必推翻“多数／倾向／风险提高”。
- 样本数大不等于样本具有代表性；选项可用抽样偏差直接切断总体外推。
- “不能支持”可能只是无关或不充分，并不必须反驳；“不能削弱”也不必须支持。选非题先标清任务。

### 4. 前提、解释、评价、一般推断须另设规则

**必要假设**：按逻辑规则否定选项，检查原论证赖以成立的必要环节是否被破坏；不是把每句都改成最极端的相反意思。桥梁只是一个常见类别，实施可行性、测量有效性、比较基准、排除特定替代解释也可能是必要假设。

**充分假设**：补入后能保证结论推出即可。它可以很强，但不一定必要。例如“有些男生是教师”加上“所有教师是研究生”足以推出“有些男生是研究生”；不能据此说“所有教师是研究生”是不可缺的必要前提。

**解释题**：保留两个表面冲突的事实，找能让两者同时成立的差异／机制，不能直接否认其中一个已知事实。

**评价题**：对选项问题分别回答“是／否”，观察是否让论证强度出现明显差异。只是相关背景问题、两种答案都不影响结论，就不是关键评价点。

**一般推断**：严格控制范围与语气，不把未提到的关系、比较或因果补进去；“不能推出”的选项无需与题干相反，只需没有获得充分依据。

### 5. 平行结构：比较完整推理形式

先抽象“前提关系 + 已知事实 + 所下结论”，对照箭头方向、量词、否定、且或关系。原论证可能无效，正确选项仍须重复其形式。题材相近、同样谈因果、结论符合常识，都不能代替形式一致。可参照[华图：平行结构解题方法](https://m.qh.huatu.com/2025/0722/1778748.html)中的翻译匹配与字母替代方法。

2026 副省 `qid19526440` 的基本式是 `P→Q；Q；所以 P`。原结论是肯后推前，并非有效演绎；选 C 不是因为 C 正确，而是它也采用该形式。

## 三、类比推理中的逻辑关系

第一步先作最短、可检验的关系描述；第二步保持角色和方向；第三步只在剩余选项之间加精细条件。多词题要核所有位置，填空题要核两侧顺序。[中公对组成与种属的辨析](https://www.eoffcn.com/kszx/detail/1252164.html)可补充“一种”与“一部分”的区别。

| 关系 | 可操作检查 | 难点与边界 |
|---|---|---|
| 全同／近义／反义 | 同指一类对象还是仅含义接近 | 近义还可能比较褒贬、程度、词性；全同与近义不要混用 |
| 种属 | A 是一种／一个 B | “A 是 B 的一部分”不是种属 |
| 组成 | A 是 B 的部分或组成要素 | 部件不是整体的一个种类；成员、机构、地理部分需明确语义 |
| 并列 | 同一划分标准下相互排斥 | 矛盾关系需穷尽给定论域；反对关系尚有其他类别；论域不能省 |
| 交叉 | 交集非空，且双方都各有交集外对象 | “有的 A 是 B、有的 B 是 A”只是同一个交集非空事实，不能排除包含或全同 |
| 原因—结果、条件 | 方向及强弱一致 | 促成不等于充分条件，必要条件也不等于原因 |
| 手段—目的／功能／原料—成品／加工 | 写清谁作用于谁，产出什么 | 空泛“有关”几乎能解释所有选项，不具有区分力 |
| 时间顺承／流程 | 顺序和参与主体是否一致 | 同一流程不保证同一主体；有先后不等于有因果 |
| 数量公式关系 | 把三个词写成同一公式并保留位置 | 单位、分子分母、减数被减数的角色必须相同 |

近期真题体现出的补充点：

- 2026 副省 `qid19526433`“减数／被减数／差”，选 B 的溶质、溶液、溶剂可写成第二量－第一量＝第三量。只认成“数学关系”不够。
- 2026 地市 `qid19526272` 护士人数／护患比／患者人数，关系为第一量÷第二量＝第三量，对应理赔总额÷平均理赔金额＝理赔次数，选 A。它是类比中的公式位置匹配，不是资料分析算数题。
- 2026 两卷共用 `qid19526255` 因果填空，两个空要同时匹配 **原因→结果**，否则可能关系相同、方向相反。
- 2026 两卷共用 `qid19526268` 用集合图考类比：①、②部分交叉，③包含于其交集。选 B，水杉属于落叶树也属于乔木。主目录误标逻辑判断，按题意应归类比。图的几何外形不是找图形规律。
- 2025 副省 `qid19283775` 光伏电站／电池板／发电，要同时满足整体—组成与功能；2025 地市 `qid19283730` 是流程先后，不能只比较三词都在同一行业。

## 四、三项代表性真题核验

### A. 2026 副省 qid19526440：平行结构，Xtest 原第 115 题／主目录第 115 题

题干由“交汇则强降雨”与“已强降雨”，推出发生交汇，形式为 `P→Q，Q，所以 P`。选 C 由“地质松软导致隧道工期延长”和“工期延长”，推出地质松软，结构相同。

反模型 `P 假、Q 真` 说明该形式本身无效。A 为正向链式推理；B、D 与给定形式不同。核验答案 **C**。原题号已与 [Xtest 2026 副省级回忆版](../Xtest/行测/2026/2026年国家公务员录用考试《行测》题（副省级网友回忆版）.md)核对。

### B. 2026 副省 qid19526436：7 选 4，Xtest 原第 110 题／主目录第 110 题

条件：甲丁至多选一；选丙或戊则选甲且不选己；选乙或庚则选丁且不选甲；总计选 4。

若选甲，不能选丁；由第三条逆否，乙庚也不能选。为凑 4 人只剩甲丙戊己，但丙／戊又要求不选己，矛盾。所以不选甲。第二条逆否排除丙戊，只余 **乙丁己庚**，恰为 4 人。

独立枚举全部 `C(7,4)=35` 组，唯一合法组也是乙丁己庚，答案 **A（安排乙庚）**。此题体现条件箭头和人数总量的联用。主目录标签误写类比。

### C. 2026 地市双打组题：Xtest 原第 106—110 题

题号依据 [Xtest 2026 地市级回忆版](../Xtest/行测/2026/2026年国家公务员录用考试《行测》题（地市级网友回忆版）.json)，另见[该卷源页](https://gwy.gkzhenti.cn/paper/1767342831759)。王、吴、韩、宋四人组成网球 T、乒乓球 P、羽毛球 B 三支各两人的队伍，每人至少参加一队；王韩不共队；韩参加 B 则宋参加 T；王参加 P 则吴参加 T，王不参加 P 则吴不参加 T。

最后两句应合成 **王P ↔ 吴T**。这是组题最有价值的基础推论。

原第 107 题 `qid19526278` 加条件“宋韩组网球”：吴不参加 T，因此王不参加 P；王也不能参加 T（与韩互斥）。王至少参加一次，故王参加 B，选 **B**。

### 明确需要补强／纠正

- 66 考点把交叉简化为“有的 A 是 B，有的 B 是 A”，没有排除全同／包含；必须补双方独有部分的要求。
- 对当方阵的全称推出特称省略非空条件，应显式补存在预设。
- “前推后充分，后推前必要”只是翻译提示，必须明确相对哪个命题说充分／必要，不能掩盖同一 P→Q 同时意味着 P 充分、Q 必要。
- 论证中用证据→结论和用原因→结果是两种不同关系，不应混成一套形式推理。
- 文本印刷第 39 页附近他因表格出现“他因加强”结尾写削弱、“他因削弱”结尾写加强的内在冲突。当前只核到 TXT，未对原 PDF 逐页验图，应标 **文本冲突待原件核验**，不贸然断定原版印错。
- “因果倒置是最强削弱类型”不宜当作无条件排序。其他原因与统计因果的界限应补反例。
- 需要加入 2025—2026 减少后的类比题量、集合图类比、平行结构、地市五题组和复杂条件量化。旧讲义零散知识点不足以覆盖从材料到模型、从模型到选项的完整操作。
- 必要假设不能只教搭桥；最新网文同样可能混淆必要与充分，须验证后吸收。

## 七、后续内容补强重点

1. 先把逻辑符号的方向、否定、量词、且或及必要／充分做成有反例的规则表，作为约束题和论证题的共同底座。
2. 论证题应按证据结构建立可重复的审查动作，同时保留选非题、程度词、比较对象和外推范围；避免“看到词就选”及固定力度排行。
3. 地市共材料题单独整理基础条件、基础推论、分支、五问复用与撤销；副省重点补人数约束混合条件句。
4. 用 2026 平行结构与集合图类比补新呈现形式；它们依赖已有逻辑能力，但不能漏识题型。
5. 类比关系表需同时保存方向、层级、量化公式、语义细分。保留可核实常识，减少没有区分力的宽泛造句。
