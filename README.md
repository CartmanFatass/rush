学习从[时政与申论学习计划（审阅稿）](学习计划.md)开始；**唯一个人记录为根目录[进度.md](进度.md)**。已有资料分析九课沿用原教学规范，状态并入统一进度。资料入口见[素材库](素材库/README.md)，修正与重算见[统计复核报告](analysis/REPORT.md)。

## 内容说明

**行测**：每卷含题目、选项、参考答案与机构解析（原导出可能标作“官方解析”），题图已本地化（3,754 张，共 3,564 题）。题目按真实模块顺序排列——政治理论 / 常识判断 / 言语理解与表达 / 数量关系 / 判断推理 / 资料分析——题号连续编号（副省级 1–135，地市级与行政执法 1–130）。选项后标 `√` 的是题库参考答案。

2022 年副省级为 134 题：该年回忆版缺 1 道数量关系题，其余年份题数与实际考试一致。

**申论**：每卷含注意事项、给定材料、作答要求，文末附参考答案。2022–2023 年部分卷附有两到三个不同机构版本的答案，已用【参考答案一】【参考答案二】区分。

## 来源

- 行测：`ERRRC/xingcezhenti`（开源仓库，2016–2026 国考+省考行测真题，55,000+ 题），原始形态按模块拆分为单文件，本目录按卷合并并重新连续编号。
- 申论：南方公务员考试网（`gwypass.cn`）历年真题栏目，考生回忆版。

本仓库题本来自考生回忆与机构复盘，未取得对应题目的官方答案或评分细则；个别表述、选项顺序可能与原卷有出入。原件保留，教学修正放在手册与研究报告中。
