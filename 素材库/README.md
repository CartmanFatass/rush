## 使用边界

1. 按准确命题、含义、来源时间、易混对照和逐项辨析学习。错误可能有多处，不预设只换一个词。
2. 限定材料题以题本为依据；外部专题辅助理解。机构答案及模型解释都可以质疑并回查。
3. 提前量、报道热度、文本相似只作研究线索，不作为命题概率、押题排序或排除知识的依据。
4. 自编题与真题分开；看过答案的题用于复盘或修订。是否完成和掌握，以实际学习记录为准。
5. 复习汇编可以精练；正式教学要讲清完整逻辑，按学习计划展开。
