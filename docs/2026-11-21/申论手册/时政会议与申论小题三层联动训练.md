# 时政会议与申论小题三层联动训练手册

> **文档定位**：将 `CartmanFatass/rush` 仓库中的**时政会议考点**、**2022–2026 国考 30 道非作文小题真题**与**大作文 8 组元主题**打通为一体化的“三层联动训练体系”。建议存入仓库 `申论手册/` 或 `素材库/` 目录，并直接对照根目录 `进度.md`（P/S/W 节点）执行打卡。  
> **联动铁律**：同主题捆绑推进（**10 分钟时政辨析 + 20 分钟小题实作 + 10 分钟复盘入卡**），但严守三线边界——**时政**记原词、数字、位次；**小题**用会议知识听懂治理逻辑，落笔严格忠于材料动词链与证据门槛，绝不拿大词覆盖细节；**大作文**再把小题拆出的微观机制与宏观口径拼接成高分论证段。

## 一、第一层：最小确定集合（5 大高频治理小集合，投入 70% 精力）

仓库 2022–2026 国考副省、地市 10 套卷共 30 道小题中，约 **75%** 的题目反复落在这 5 个治理小集合内，且与 2025–2026 核心会议高度重合。

### 1.1 实体企业突围与产业升级

- **时政会议锚点（P 线）**
  - **2025 年中央经济工作会议**：五个“必须”中强调“既‘放得活’又‘管得好’”（注意 2024 年为“管得住”）；八项任务首位为“坚持内需主导，建设强大国内市场”；明确“制定全国统一大市场建设条例，深入整治‘内卷式’竞争”（[国家发改委培训中心专题](https://www.ndrctc.org.cn/mdgzlfz_ghjjxlt/)）。
  - **2026 年政府工作报告**：“着力建设强大国内市场”居十大任务之首；GDP 增长预期目标设为区间 **4.5%–5%**；深化拓展“人工智能+”，打造智能经济新形态（[人民日报 2026 政府工作十大任务](http://paper.people.com.cn/rmrb/pc/content/202603/07/content_30143843.html)）。
  - **“十五五”规划纲要**：全社会研发经费投入年均增长 **7% 以上**；因地制宜发展新质生产力，防止一哄而上。
- **对应真题习题清单（S 线）**
  - `2022 副省一`（10 分 / 200 字 / ①做法启示）：B 公司案例提供了哪些启示
  - `2022 地市四`（15 分 / 350 字 / ④原因分析）：黄总为什么有这样的信心
  - `2024 副省一`（10 分 / 200 字 / ①做法经验）：总结“耀然灯饰”成功的经验
  - `2024 地市二`（15 分 / 300 字 / ④原因分析）：隆金公司为什么能成为“市场中的主角”
  - `2026 地市一`（10 分 / 250 字 / ①做法优化）：物流中心如何提供和优化铁路物流服务
- **小题高频得分机制词**
  - 专注细分市场、持续质量改进与核心研发投入、精准对接市场与客户需求、整合全流程服务、打通运输衔接减少中间转运、推动传统产能数智化升级。
- **易踩坑与证据边界**
  - 问“做法”时（如 `2026 地市一`），**绝不能用“绿色物流、成本降低”等结果词代替通道、费用、能力、服务环节的具体动作**。
  - 问“原因”时（如 `2024 地市二`），**绝不能只罗列所获奖项和荣誉**，必须写清研发、管理、定位如何形成市场竞争力。
- **大作文元主题接口（W 线）**
  - 挂接 **W02（制造业中试转化）**、**W05（晋江国盛鞋材依托基础升级）**、**W06（规则兼容与全国统一大市场）**。

### 1.2 乡村发展与基层利益联结

- **时政会议锚点（P 线）**
  - **2026 年中央一号文件**（2026-01-03 成文 / 02-03 发布）：《中共中央 国务院关于锚定农业农村现代化 扎实推进乡村全面振兴的意见》，系“十五五”首个、十八大以来第 **14 个**指导“三农”的中央一号文件（[中国网信网 6 图速览](https://www.cac.gov.cn/2026-02/05/c_1772021793867283.htm)）。
  - **2026 报告与“十五五”纲要数字对照**：年度粮食产量 **1.4 万亿斤左右**，五年粮食综合生产能力 **1.45 万亿斤左右**（约束性指标）；高标准农田强调建设、运营、管护机制“建一块成一块”。
  - **规范称谓切换**：统一使用“乡村全面振兴”“脱贫人口”“巩固拓展脱贫攻坚成果”“农业转移人口市民化”。
- **对应真题习题清单（S 线）**
  - `2023 副省二`（15 分 / 250 字 / ④原因分析）：为什么村民说“从旁观者变成参与者再到传承者”
  - `2024 地市一`（10 分 / 250 字 / ①做法概括）：冯教授团队怎样当好“运营官”
  - `2025 地市三`（20 分 / 450 字 / ⑥成效+对策）：林票改革——梳理成效，提出深化改革的建议
  - `2026 地市二`（15 分 / 300 字 / ②成效归类）：“三效”（经济、社会、生态效益）的具体体现
  - `2026 地市四`（20 分 / 450 字 / ⑥原因+对策）：共享村落——阐述推进缓慢的原因，提出建议
- **小题高频得分机制词**
  - 尊重乡村主体与乡土文脉、参与式共创、专业经营带动资源价值实现、完善利益联结与履约约束、补齐基础设施与生活服务配套、实现经济/社会/生态“三效”统一。
- **易踩坑与证据边界**
  - `2026 地市二` 切忌把农业技术名称当效益，必须写明受益对象与实际产出。
  - `2025 地市三` 切忌把远期目标当已有成效，也不能提出“无条件放贷”类脱离风控的对策。
  - `2026 地市四` 切忌由配套与协调困难直接升级扣帽为“推诿扯皮、形式主义”。
- **大作文元主题接口（W 线）**
  - 挂接 **W04（做优增量与盘活存量，兼顾文化保护与使用价值）**、**W05（因地制宜匹配产业基础）**。

### 1.3 生态保护与绿色价值转化

- **时政会议锚点（P 线）**
  - **“十五五”规划纲要 20 项指标**：含 **8 个约束性指标**，其中 **5 个为绿色低碳指标**；单位 GDP 二氧化碳排放五年累计降低 **17%**，森林覆盖率达到 **25.8%**（[新华网两会新华视点](https://www.news.cn/politics/20260306/cbd5fa08e51d48f299b8228278f693a8/c.html)）。
  - **2026 年政府工作报告**：首次用碳排放强度目标取代能耗强度目标（单位 GDP 二氧化碳排放降低 **3.8% 左右**，2025 年为能耗降 3% 左右）；实施碳排放总量和强度双控制度，完善碳足迹管理体系。
  - **《中华人民共和国生态环境法典》**：继民法典后我国第二部以“法典”命名的法律，**2026 年 8 月 15 日起施行**，开创性设立绿色低碳发展编（[新华网特稿](https://www.news.cn/world/20260814/421be0c821b24878a8f2825a673da15a/c.html)）。
- **对应真题习题清单（S 线）**
  - `2023 地市一`（10 分 / 200 字 / ①做法概括）：A 市如何利用 GEP 核算实现生态产品价值（**进度.md 既定 S1 首课**）
  - `2025 地市一`（10 分 / 200 字 / ②表现概括）：“生态实践智慧”体现在哪些方面
  - `2025 地市二`（15 分 / 300 字 / ①互动机制）：政府与企业如何良性互动实现治水
  - `2025 副省一`（15 分 / 350 字 / ④概念协同）：三条“黄河”分别指什么，如何协同发挥作用
- **小题高频得分机制词**
  - 生态产品价值核算与市场化交易转化、政府需求与企业专业能力对接、以调查与专业论证改进治理方案、监测预警与责任部门信息传递衔接、生态循环利用与生态种养、专业管护与长效运维。
- **易踩坑与证据边界**
  - `2025 地市二` 切忌把政府做法和企业做法分成两块各写各的，必须写出**双向互动链条**（政府提需求/买服务 → 企业出专业方案与技术监测 → 数据反馈优化政府决策与推广）。
  - 生态效益类表述须守住边界：局部循环利用不能夸大为“零排放”；信息传到责任部门不能直接等同于“整改闭环”。
- **大作文元主题接口（W 线）**
  - 挂接 **W08（系统治理与可靠响应：基础普查→监测预警→联动处置）**。

### 1.4 公共服务供给与基层执行

- **时政会议锚点（P 线）**
  - **二十届四中全会《建议》与 2025 中央经济工作会议**：首次鲜明提出“**坚持惠民生和促消费、投资于物和投资于人紧密结合**”；提出“制定实施城乡居民增收计划”“倡导积极婚育观，努力稳定新出生人口规模”（[人民日报理论版](http://paper.people.com.cn/rmrb/pc/content/202603/06/content_30143701.html)）。
  - **2026 报告与“十五五”纲要数字**：城镇新增就业 **1200 万人以上**；年度失业率 **5.5% 左右**，五年目标 **低于 5.5%**；人均预期寿命提高到 **80 岁**；推行长期护理保险、落实育儿补贴、逐步推行免费学前教育；灵活就业人员约 2 亿人须跟进参保与生育保险扩围。
  - **任务排序排雷**：2026 报告中民生（第 8）在绿色（第 9）之前；2025 经济会中“双碳”引领（第 6）在民生为大（第 7）之前。

  - `2024 地市四`（20 分 / 450 字 / ⑥问题+对策）：公共文化空间——梳理问题，提出解决建议
  - `2025 副省四`（20 分 / 400 字 / ⑥问题+对策）：梳理问题，提出建议
  - `2026 副省四`（20 分 / 400 字 / ⑥问题+对策）：梳理管理和运营两方面问题，提对策
- **小题高频得分机制词**

- **易踩坑与证据边界**

### 1.5 治理工具边界与执行纠偏（党建与政绩观暗线）

- **时政会议锚点（P 线）**
  - **二十届五中全会《决定》**（2026-10-26 至 29）：审议通过《中共中央关于持之以恒推进全面从严治党若干重大问题的决定》，提出**七条原则**、**九项系统部署**，明确形成**习近平党建思想**（“十四个坚持”），决定党的二十一大于 2027 年下半年召开（[二十届五中全会公报](https://www.news.cn/politics/leaders/20261029/3dc769be3bff40aeafcbf957eb4e47bb/c.html)）。
  - **五中全会必背排雷**：两个答案先后不可颠倒（第一个“让人民来监督政府”，第二个“自我革命”）；七个部分定性词（根本性任务、内在要求、关键在从严治吏、主体、有力举措、重要方略和基本方针、长远之策和根本之策）不可互换。
  - **正确政绩观与基层减负**：2026 年在全党深入开展**树立和践行正确政绩观学习教育**（为人民出政绩、以实干出政绩，完善差异化考核评价体系）；落实**乡镇（街道）履行职责事项清单**，持续为基层减负赋能（[人民日报 2026-11-18](https://paper.people.com.cn/rmrb/pc/content/202611/18/content_30191815.html)）。
- **对应真题习题清单（S 线）**
  - 贯通所有 ⑥ 类问题+对策大格题（如 `2024 副省三` 基层“两难”心态、`2026 副省四` 管理与运营问题、`2026 地市四` 共享村落推进缓慢），以及行测政治理论高频辨析。
- **小题高频得分机制词**
  - 台账服务实际工作避免过度留痕、考核评价指标贴合真实工作目标、杜绝应付检查式无差别关停（一刀切）、区分多头申报与多头管理、严格区分制度本身与执行走样、以群众实际获得校正治理行为。
- **易踩坑与证据边界**
  - **反过度泛化**：不能见到“台账、考核、督查”就自动标为问题词；只有在材料给出“重留痕轻实效、指标脱离实际”证据时，才定性为形式主义。
- **大作文元主题接口（W 线）**
  - 挂接 **W07（正确政绩观与治理实效：北京深化“接诉即办”从办一件事到治一类事）**。
