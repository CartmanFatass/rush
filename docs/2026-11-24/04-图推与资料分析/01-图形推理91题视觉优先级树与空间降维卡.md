### 一、“第一眼视觉特征 → 考点优先级”索引树

#### 1. 总入口：先判断什么在变

```text
看到题图
├─ 外轮廓、格子或圆点位置基本不变，只变黑白
│  ├─ 九宫格／两组类比 → 先同位运算，再位置变换
│  └─ 单行序列 → 先追踪局部位置，再数量／连通性
├─ 每幅轮廓不同，但明显都有对称结构
│  └─ 先对称轴及其穿过位置，再角／边数量
├─ 方框内有大量分割线
│  ├─ T接头、交叉、出头明显 → 先笔画／奇点
│  └─ 小区域形状清楚 → 先面的形状与数量
├─ 圆与折线接触非常醒目
│  └─ 先切、交、端点连接，再笔画／连通性
├─ 多个互不相连的小图元
│  └─ 先开闭性、种类数量，再整体数量关系
├─ 大块黑色多边形，旁有白色区域
│  └─ 先边角比较或边界接触，再面积／邻接
└─ 立体、展开、切割、折纸
   └─ 直接进入空间操作卡，不走平面数量穷举
```

**注意：“六图分两类”是题式，不是几何外观。**  
不能因为都是分类题，就统一先查对称或统一先数笔画。

### 二、空间重构与立体图：降维防错操作卡

#### 卡1：普通六面体——“先相对，后共边，最后朝向”

**适用：**2022-4637401、2022-4639349。

1. 在展开图上标出三对相对面。
2. 同时可见的三个面不能含相对面。
3. 剩余选项只核一个有偏心标记的面：标记靠哪条公共边、哪个公共顶点。
4. 转动可以，镜像不可以。

**口诀：**
> **相对不相邻，偏心找共边；图案种类对了，朝向还得验。**

本批例子：
- **4637401**可以用带居中标记的面的相对关系识别异项，选 C。
- **4639349**还要核小方块贴边方向，不能只核“黑面、白面是否相邻”，选 A。

#### 卡2：四块小面拼成一个大面——“先拼面，再转面”

**适用：**2023-5445923。

不要把四个小箭头当成四个独立的正方体面。

1. 先确定四块小面折后共同组成缺失的那一面。
2. 给四个象限编号，分别记录箭头相对公共边的方向。
3. 拼成完整的 \(2\times2\) 箭头面后，允许整个面旋转匹配选项。

**口诀：**
> **四小块先合一大面，箭头跟着折边转。**

本题盲判 **B**。

#### 卡3：彩色小方块长方体展开——“先分六面，别逐格硬折”

**适用：**2024-5893661、2024-5895236。

两题都是 \(3\times2\times2\) 长方体，外表面共有：

\[
2(3\times2+3\times2+2\times2)=32
\]

个单位小格。

操作顺序：
1. 将选项先切分成四个 \(3\times2\) 面、两个 \(2\times2\) 面。
2. 对照相对面及长短边关系。
3. 再核颜色沿公共棱能否接上。
4. 同一个彩色小正方体，可能在两个或三个外表面露色；**4个彩色方块不等于4个彩色表面格**。

**口诀：**
> **先六面，后小格；一块多面露色，公共棱两边对账。**

这两题选项小格很密，本次未完成逐格核对，不报确定字母。

#### 卡4：立体拼合——“底层画格，上层写数，已知块做减法”

**适用：**
2022-4637338；2023-5445798、5445914；2024-5893669、5894887。

1. 画底面格，给每一列写高度。
2. 灰色方块单独记录坐标，不只记“有几个灰块”。
3. 优先放受限结构：三层柱、长臂、凹槽、突出角。
4. 从总图逐格扣掉①②，检查残块是否连通、数量与颜色是否一致。

**口诀：**
> **高柱先占位，灰块定坐标；总图减两块，余形才是答案。**

防错：
- 看不见的方块不能直接当不存在。
- 体积、灰块数正确只是必要条件，不足以证明可拼。
- 整块旋转时，灰色也必须跟着走，不能单独换灰块位置。

#### 卡5：任意截面——“外轮廓切一次，空洞再减一次”

**适用：**
2022-4637364、4637564；2023-5445843。

先分别考虑：
- 平面与外实体相交是什么形状？
- 同一平面与挖空部分相交是什么形状？
- 后者从前者中扣除，得到截面。

**口诀：**
> **先切外壳，再减空洞；选项要能给出同一张切平面。**

本批：
- **4637564**：水平截取空心部分可得圆环，选 B。
- **4637364**：优先找能形成高低台阶的纵向截法，盲判 C。
- **5445843**：不能把不同高度才可能出现的完整截形，随意拼到同一截面中；暂判 A。

特别注意：**“有平面角，所以一定能切出任意三角形”不成立。**

#### 卡6：指定经过 A、B、C 的截面——“三点定面，逐层取格”

**适用：**2024-5893673、5894980。

1. 以小正方体棱长为1，给 A、B、C 写坐标。
2. 确定切平面，再按高度分层。
3. 每层只取真正被切过内部的方块。
4. 同时记录对应方块颜色，最后拼截面。

**口诀：**
> **先定平面再涂色；擦过顶点、沿过棱，不多算一块面。**

这类题不要先盯选项灰格猜答案。外形相同，灰块归属仍可能不同。

#### 卡7：视图——“投影看遮挡，连通体不能凭空断开”

**适用：**2023-5445823。

该立体本身连通，正投影的整体轮廓也应连通。选项 C 的两条横条彼此分离，可以直接排除。

**口诀：**
> **先看连不连，再看挡不挡，不必先转三遍。**

本题问“不可能”，选 **C**。

#### 卡8：折纸面积——“算覆盖并集，不把各块直接相加”

**适用：**2023-5445822。

沿折痕反射各区域，区分：
- 哪些构成最终外轮廓；
- 哪些重合；
- 哪些完全被覆盖。

本图折后可按 \(b,d\) 的覆盖并集计算，重合扣除 \(a\)，得到：

\[
b+d-a
\]

选 **D**。

### 一、“第一眼视觉特征 → 考点优先级”树状索引

#### 1. 总入口：先看“什么保持不变”


##### 三条已经能明显节省试错的区别

1. **83883 与 26250：同样像七巧板，入口不同。**

### 二、空间重构与立体图“降维防错操作卡”

#### 卡1：六面体展开——“面定邻接，边定方向，角定手性”

适用：83845、26329、26393。

1. **先给六个面编号。**重复字母、重复色块也要分别编号。
2. **找相对面。**相对面不能在同一个立方体可见角处相邻。
3. **固定一条公共边。**标记图案在线边的哪一侧、端点靠哪个角。
4. **最后核朝向。**字母头部、C的开口、三角尖端、黑色角块都不能省略。

口诀：

> **只对面，不够；公共边对上，方向才算对上。**

- **83845候选 D**：不能仅比较“A对A、C对C”，还要核验字母朝向。
- **26329候选 D，即①与③**：两只立方体分别核验图案与公共边的对应，不能把两个立方体的可见面混成一只的邻接关系。
- 26393尚未完成所有色块方向核验，不给定案。

#### 卡2：小正方体组成的长方体展开——“黑的是体素，不是独立贴纸”

适用：83952。

1. 先按尺寸划清六个大面，**不能把每个小格当作一个独立面**。
2. 把可见黑格还原为同一个黑色小正方体。
3. 沿公共棱检查相邻面的颜色是否一致。
4. 再核四个黑色体素是否足以解释全部黑色面格。

防错：

> **一个黑色角块可能在展开图上出现三块黑面；三个黑面不等于三个黑块。**

仅数展开图黑格总数通常不足以定案。

#### 卡3：立体拼合——“先占位，后上色；先放最受限件，再查余块”

适用：83877、83916、26323、26428。

把目标写成按层排列的占位格：

- 底层哪些位置有方块；
- 第二层哪些位置有方块；
- 更高层有哪些突出；
- 灰块分别在哪个三维位置。

操作顺序：

> **体积初筛 → 高柱、凹槽定位 → 限制最强的拼块先放 → 目标减去已放拼块 → 剩余体素逐格核对。**

必须检查：

- 无重叠；
- 无空缺；
- 不越出目标；
- 灰块位置正确；
- 只允许旋转，不允许镜像替换。

**83877不能仅凭总体积判断“不可能”。**四个选项若体积一致，还要证明至少存在一次完整拼合，或找到无法满足的占位约束。

**26323与26428必须分别核验。**题干和目标很像，不足以认定拼块选项完全等价。

#### 卡4：截面——“先定平面，再逐层求交；不抄立体外轮廓”

适用：83859、83965、26333。

1. 在 P、Q、R 中先找一条方向最明确的连线。
2. 判断截平面沿哪个方向高度不变、沿哪个方向升降。
3. 在各个凸起、台阶、凹槽中分别求交。
4. 按空间位置把交线接回同一平面，合并共线边。
5. 检查是否存在**断开的截面部分**。

口诀：

> **同一平面不等于连续一片；凹体切开可以断。**

防错要点：

- 不能把可见的台阶轮廓直接当截面；
- 截面顶点应对应截平面与原体棱边的交点，或凹凸转换处；
- 只“碰到”某条棱或某个点，不应随意画成有宽度的凸块。

**26333候选 B**：按截面推进，较高柱体对应中部较高的截面部分，而不是把原图左侧轮廓照搬下来。83859、83965尚未完成逐层求交验证。

#### 卡5：三视图——“长对正、宽相等、高平齐；颜色看遮挡”

适用：26397。

1. **俯视图定占地**，不是直接给每个位置的高度。
2. **左视图定各深度列的最高高度**。
3. 与正视图候选的宽度、高度逐列对应。
4. 用总体积约束排除无法达到方块总数的配置。
5. 对黑格检查沿该观察方向是否被其他方块遮挡。

最重要的防错句：

> **视图中的黑格是该方向可见的黑面，不是这一整列都黑；不同视图里的黑格也不能直接相加。**

26397候选 **B**。判定应同时使用总体积和颜色遮挡，而不是只比轮廓。
