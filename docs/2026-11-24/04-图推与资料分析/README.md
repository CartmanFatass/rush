## 一、模型配置、白底转 RGB 读图流水线与成本账单

### 1.1 多模态盲测流水线口径

1. **模型与推理档位**：统一调用 `gpt-6-astra`，配置 `reasoning: { mode: "pro", effort: "high", context: "all_turns", summary: "detailed" }`，`service_tier: "flex"`，`background: true`。
2. **白底转 RGB 读图预处理**：针对题库原始 PNG 切图存在透明通道（Alpha 背景）或灰阶模式、在多模态渲染中易把黑色线条/实心图元与暗底混溶的问题，输入端统一经**白底合成转标准 RGB 图像流水线**处理后嵌入多模态请求，消除“因底色吞线导致误读”的工程噪声。
3. **严格盲测纪律**：输入仅含题干、材料图表与题目切图（含穿插的非本模块共用材料，由模型自行识别剥离），**不提供任何官方答案、题库标签或机构解析**。图形推理明确要求区分“已完成排他验证的候选答案”与“仅提出首试方向但未完成逐格/三维排他验证的 `null`”，严禁把未证完的题目硬猜字母或甩锅给“原图模糊”。
