### 二、术语零误判速查卡

统一记号：现期量为 \(X_1\)，基期量为 \(X_0\)；部分为 \(A\)，整体为 \(B\)；部分、整体同比增长率分别为 \(a,b\)。增长率均按带正负号的小数代入。

| 题干字眼 | 唯一确定分子、分母或算式 | 禁区警报 |
|---|---|---|
| “同比增长/下降” | 增长率＝本期与**上年同期**之差÷上年同期量 | 2021年1—2月须比2020年1—2月，不能比2020全年 |
| “比上月”“环比” | 增长率＝本月与上月之差÷**上月量** | 2020年1月的上月是2019年12月，不是2020年12月 |
| “增长多少件/亿元”“同比增量” | \(\Delta X=X_1-X_0=X_1r/(1+r)\) | 增长量带单位；不能直接用 \(X_1r\)，除非只是有误差控制的估算 |
| “增长了百分之几” | \((X_1-X_0)/X_0\) | 分母不是现期量；下降率按带符号增长率处理 |
| “增速高多少个百分点” | 两个增长率直接相减 | 不再除以其中一个增长率 |
| “比重提高几个百分点” | 两个比重直接相减 | 由20%到25%是提高5个百分点，不是提高5% |
| “现期占比” | \(A_1/B_1\) | 分母必须是同期间、同范围整体 |
| “基期占比” | \((A_1/B_1)(1+b)/(1+a)\) | **整体增长率在分子，部分增长率在分母** |
| “比重比上年上升/下降” | \(\Delta p=(A_1/B_1)(a-b)/(1+a)\) | 分母是 \(1+a\)，不是 \(1+b\)；方向由 \(a-b\) 决定 |
| “平均每个/每亩/每吨” | 平均数＝总量÷对应数量 | 亩产＝产值÷价格；进口单价＝进口额÷进口量 |
| “平均数增长率” | \((a-b)/(1+b)\) | 分母是**数量增长因子**；不是简单的 \(a-b\) |
| “两期平均数相差多少” | \((A_1/B_1)(a-b)/(1+a)\) | 结果有平均数单位；不能回答成百分数 |
| “年均增加多少” | \((X_n-X_0)/n\) | 2013—2022年以2013年为基期，间隔是9年 |
| “年均增长率” | \((X_n/X_0)^{1/n}-1\) | 相同年数只排序时，比较末期÷基期即可，不开方 |
| “累计”“当月”“第二季度” | 当月＝本月累计－上月累计；第二季度＝上半年－第一季度 | 累计量不能直接当单月量 |
| “顺差/逆差” | 顺差＝出口－进口；逆差＝进口－出口 | 不能把进出口总额当差额，也不能颠倒符号 |
| “新增部分占比”“累计占比变化” | 新增部分占比高于累计占比，则累计占比高于原有占比 | 新增结构不是同比增长率；存量结构不能直接替代新增就业结构 |

#### 本批特别需要锁死的四条防呆规则

1. **受理率、合格率：整体包含未受理、不合格。**  
   受理率超过75%等价于：受理量＞3×未受理量。

2. **分数之差不能错合分母。**  
   电话投诉占比减电话举报占比，必须分别除以投诉总量、举报总量。

3. **不能先截位再做接近数相减。**  
   用户净增、收入增量、季度累计差，应先用原数作必要减法，再估算商。

4. **单位换算先写清。**  
   1亿＝10000万；1万吨＝1000万公斤；1GWh＝1000MWh。  
   “万公斤÷万吨”不换单位会直接错1000倍。

### 三、算式结构 × 选项间距：停止计算决策树

#### 第一步：先确定选项究竟区分什么

- **排序、方向、趋势图**：只求足以确定顺序、正负或拐点的信息。
- **区间选项**：只与区间边界比较。
- **近似数值选项**：将数值排序，以相邻选项的**中点**作为判项边界。
- **判断有几项**：逐项判真伪，不能按“多数看起来正确”推断。

#### 第二步：优先做结构判断

依次检查：

1. 能否直接读数、计数？
2. 能否只比较增长率，判断比重或平均数方向？
3. 能否利用“大分子、小分母”直接比较？
4. 能否利用累计增速的加权平均关系？
5. 能否用总量上界、下界直接越过选项边界？

命中任意一种且已唯一确定选项，**禁止再算完整比值**。

本批典型：

- **4637426**：产值增速分别高于价格增速，两种亩产均增长。
- **4639490**：累计增速上升，当月增速就高于本期累计增速。
- **5445861**：比重下降，下降幅度小于2.4个百分点，直接落入“不到3个百分点”。
- **5893792**：五年每年都不足1800万吨，总和必不足9000万吨。

#### 第三步：不做除法，先反推阈值

常用替换：

- \(A/B>c\) → 比较 \(A\) 与 \(cB\)；
- 合格率＞95% → 不合格量＜总量的5%；
- 单月高于其余11个月平均 → 该月×12＞全年；
- 年末总量增长超过100% → 现期＞2×基期；
- 比较同年数年均增速 → 比较末期÷基期，不求根。

#### 第四步：需要算时，先短计算，再估商

正确顺序：

> **原数必要加减 → 约分/抵消/特征值转换 → 两位估算 → 检查是否唯一落档。**

不能倒过来“先粗化大数，再相减”。

对正数比值，如分子、分母分别位于区间内，则：

\[
\frac{N}{D}\in\left[\frac{N_{\min}}{D_{\max}},\frac{N_{\max}}{D_{\min}}\right]
\]

只要整个结果区间属于同一选项判定区，就停止。若跨界，只提高**造成跨界的那一项**精度，不全面重算。

#### “绝不准多算”的准确边界

> **不是“算到两位就必须停”，而是“已有足够信息唯一判项，就必须停”。**

- 已知比重下降且幅度必小于3个百分点，不求具体下降1.80还是1.79。
- 已知全年合计超过3.6万亿元，不求精确到亿元。
- 已知曲线是“先降、再升、再升”，不计算同比增量增长率。
- 估值仍可能跨越边界、相等关系尚未排除时，**不能停**。

统一记号：现期分子为 \(A\)，现期分母为 \(B\)，各自增长率为 \(a、b\)，均按小数代入。

#### 1. 最容易写反的核心映射

| 题干字眼 | 唯一列式或分子、分母 | 禁区警报 |
|---|---|---|
| **同比增长率** | \((本期-上年同期)/上年同期\) | 同比不一定是全年；三季度对上年三季度，3月对上年3月 |
| **环比增长率** | \((本期-紧邻上期)/紧邻上期\) | 本批“第15届环比”对第14届；9月环比必须取8月 |
| **同比/环比增长量** | \(现期-基期=现期\times r/(1+r)\) | 不能写成现期×增长率；后者通常高估正增长量 |
| **增长了多少百分比** | 差额÷原来的量 | 分母是基期，不是现期 |
| **提高多少个百分点** | 两个百分数直接相减 | 10.75%增加5个百分点是15.75%，不是10.75%×1.05 |
| **现期比重** | 现期部分÷现期整体，即 \(A/B\) | “出口占出口”不能除以进出口；“集中式”不能除以全部项目 |
| **基期比重** | \(\frac AB\frac{1+b}{1+a}\) | 分子分母都要还原；不能只还原部分 |
| **比重同比上升多少个百分点** | \(\frac AB\frac{a-b}{1+a}\)，再×100 | 符号看 \(a-b\)；分母是**部分增长率的1+a** |
| **比重比上年增长百分之几** | \((a-b)/(1+b)\) | 这是比重的相对增长率，不是百分点差 |
| **平均数增长率** | \((a-b)/(1+b)\) | \(a\)对应总金额等分子，\(b\)对应笔数等分母 |
| **两期平均数差** | \(\frac AB\frac{a-b}{1+a}\) | 分母换成**分子增长率的1+a**；结果带元、万元/件等单位 |

**统一防呆式：**对任何比值 \(F=A/B\)，

\[
F_0=F\frac{1+b}{1+a},\qquad
\frac{F-F_0}{F_0}=\frac{a-b}{1+b},\qquad
F-F_0=F\frac{a-b}{1+a}.
\]

先识别题目要的是**比值、比值的增长率，还是比值的差**，再选式子。

#### 2. 本批必须加上的口径补丁

| 真实问法 | 正确处理 | 禁区警报 |
|---|---|---|
| “截至某年累计”与“某年核发量” | 当年量＝本年累计－上年累计 | 19526367不能直接用22075÷5954 |
| “平均每件已产业化专利收益”改问“每件有效专利收益” | 原平均收益×产业化率 | 分母从已产业化专利扩展到全部有效专利 |
| “平均每万人次中……” | 部分人次÷总人次×10000 | 不能直接报百分数；不能平均三个假期的比重 |
| “进出口同比增长率” | 出口、进口分别还原基期后合并 | 不能把出口增速、进口增速简单平均 |
| “保持同比增量不变” | \(X_n=X_0+n\Delta\) | 是等差，不是复合增长 |
| “第一次超过” | 找满足严格 \(>\) 的最小整数期数 | 恰好等于不算超过 |
| “增长27.8倍” | 现期＝基期×28.8 | 与“是27.8倍”不同 |
| 亿、万及货币单位混合 | 先统一单位再作差、作比 | 本批支付材料同时有万亿元、亿元、亿美元 |
| “能够推出” | 检查所需变量是否齐全 | 不能把总体增速套给细分领域，不能把分组均值简单平均 |

### 三、算式结构×选项间距：三元决策树

#### 第一步：先问“需要数值，还是只需要关系？”

下列情况优先停在第一档：

1. **可计算性判断**：缺不缺基期、权重、交叉分类数据。
2. **正负判断**：比重、平均数变化的方向先看 \(a-b\)。
3. **排序支配**：正分数中，分子更大且分母更小，直接更大。
4. **图形排除**：先看正负、最大最小、升降顺序，不求全部占比。
5. **宽松界已经覆盖阈值**：例如已证明下降幅度不到600元，就不必再求究竟下降493元还是495元。

**只确定方向还不够。**如果选项同时区分“上升不到2个百分点”和“上升2个百分点以上”，必须再给一个幅度上界或下界。

#### 第二步：把四个选项变成“判选边界”

- **数值近似题**：排序后看相邻选项的中点。
- **区间题**：直接看题目给出的区间端点。
- **计数题**：精度由每个对象与统计阈值的距离决定，不由“A到D相差1”决定。
- **排序、趋势、饼图题**：没有可套用的数值选项间距；只检查能区分选项的关系。

例如：

- 19526370的395、409、468、502，对B有用的判选区间是 **402～438.5**。
- 19283941虽然选项只是3、4、5、6，但真正危险的是杭州票价与**40元**的距离。
- 19526363的实际门槛是**44万亿元、45万亿元**，不是笼统地“约44”。

#### 第三步：先用两位区间，不能唯一落档才升级

对正数分式，若已取得上下界：

\[
A\in[A_L,A_U],\quad B\in[B_L,B_U],
\]

则

\[
A/B\in[A_L/B_U,\ A_U/B_L].
\]

只要这个区间完全落在同一个选项的判选区域内，**立即停止，多算一位没有判选收益**。

特别注意：

- **相减会放大相对误差**：先保留原数作差，再对差额粗估。
- **多个数求和会累积误差**：不能把每项随意舍入后，忽略总误差。
- **“保留三位”也不是万能保证**：真正的停止条件始终是“不跨边界”。

#### 四个值得固化的短计算改写

1. **19283745：比值接近0.9，不必硬除。**  
   改查“申请量－发证量＜申请量的10%”。2016、2023符合。

2. **19283973：平均价微升，不必逐年算到小数。**  
   2021→2022零售额约降6.7%，零售量约降7.1%，所以均价上升。

3. **19526370：相邻答案近，也未必需要三位商。**  
   上年全年进口在4900～5000亿元，上年12月在430～440亿元，因此1～11月月均在约405～416亿元，已经唯一对应409。

4. **19526443：避免两个基期相减造成精度压力。**  
   用基期权重 \(w\)：
   \[
   g_{1—2月}=54.4\%+(54.4\%-31.9\%)\frac{w}{1-w}.
   \]
   只需判定 \(0.4<w<0.5\)，就得到约69.4%～76.9%，完整落入65%～85%。

**考场停止口令：关系已唯一，停；估计区间已唯一，停；只剩一个临界对象，只精校这个对象。**
