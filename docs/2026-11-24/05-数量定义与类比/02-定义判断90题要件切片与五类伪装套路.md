## 一、90题结构与“切片锚点优先级”

### 1. 统计口径与结果

仅统计90道定义判断题。夹入的货架、值班、城市结对、会议、双打比赛材料与这些定义题无关，**全部剥离，不据此补充条件或日程假设**。

为避免同一道题重复计数，采用以下主标签规则：

1. **公式/规则定义**：核心是比例计算、数值决策、符号位序或形式逻辑映射。
2. **图文定义**：其余题中，需要读取图表、关系网络或空间结构才能完成匹配的题。
3. **多定义**：出现多个可独立提取要件的具名概念，包括上下位定义。
4. **单定义**：其余题。一个定义内部列举若干表现，不自动算多定义。

例如：收益表题归“公式/规则定义”；深度优先搜索题归“图文定义”；“慢病＋慢病自我管理”归“多定义”。

### 2. 先锁问法，再切要件

建议把定义压成以下“槽位”，但**原文没有的槽位不补，原文中的“或”不改成“且”**：

> **谁／什么对象＋满足什么条件＋采用什么方式＋为了什么／造成什么结果＋哪些情况排除**

读题优先级不是机械地从头读到尾，而是：

> **问法与目标定义 → 明确排除、数量边界及区别性门槛 → 主体／客体 → 条件与方式 → 目的／结果**

“仅、必须、全部、未、同一、不超过、直接”等限定词，应与其修饰的内容一起划出。

| 题型 | 优先划出的要件顺序 | 本批实例 |
|---|---|---|
| 单定义 | 主客体 → 特殊条件／方式 → 目的结果 → 排除限定 | 基因污染：**外源基因→扩散到其他对象→成为后者基因的一部分** |
| 多定义 | 问的是哪一个 → 各定义差异项 → 交集／并集要求 → 共有条件 | 限性遗传：**性染色体＋只在一种性别表现**，不能只抓后半句 |
| 公式/规则定义 | 参数含义与单位 → 分子分母／位序／量词 → 运算或推理方向 | 动销率：分子分母均为**品种数**，不是商品件数 |
| 图文定义 | 图例 → 节点或行列代表什么 → 方向／连线 → 数量与结构约束 | 人际关系图：先认清 **A→B表示A受B吸引**，再统计实线入箭头 |

#### 为什么多数题不必先读懂专业术语？

因为选项通常不是考查术语的完整知识体系，而是考查**是否满足题干设定的关系结构**。术语名称可以暂时替换成“定义D”。

例如：

- **生化选择性**：只需抓“作物与杂草的代谢、解毒差异”。叶片宽窄属于形态差异，直接排开。
- **同种数罪**：只需抓“同一行为人＋多个行为＋相同罪名”。不同罪名再严重也不符合。
- **形象史学**：只研究雕刻技法，不能代替“结合文献研究历史”。
- **在制品控制**：直接对象是生产物料，不是员工洗手行为。

但这不是“看到关键词就选”。**出现同一个词，不等于关系相同；结局相似，不等于方式满足。**

反排时还要区分：

- **明确冲突**：可以直接排除。
- **关键要件没有交代**：先记“证据不足”，不能一律当作明确不成立。
- **无冲突**：只是保留，尚不等于最终成立。

### 3. 新型题的“第一步对齐法”

先问：**这个参数、符号、箭头或位置，究竟代表谁对谁？**

| 类型 | 第一步对齐 | 本批验证 |
|---|---|---|
| 比例定义 | 写清“分子对象／分母对象”，检查单位一致 | 2022-4637373：抚养比是非劳动年龄人数／劳动年龄人数；两个系数之和是非劳动年龄人数／总人口。一般正值情形下前者更大，选A |
| 同分子比率 | 先比较分母集合大小，不先算数 | 2024-5893817：可流通馆藏≤全部馆藏，因此同分子、正分母时，流通率≥利用率，选A |
| 收益矩阵 | 行＝方案，列＝自然状态；先行内取值，再跨行比较 | 2023-5445859：各行最小值为−40、−80、16，选方案三；最大值为180、240、100，选方案二，选D |
| 符号编码 | 先定高位在哪，再定各位置的符号大小序 | 2024-5893601：**右边是高位**。A、C先胜出；再比较左位，黑菱形大于黑方块，选A。无须擅设具体数值 |
| 关系网络 | 节点＝成员；线型＝关系类别；箭头＝关系方向 | 2024-5893605：中心看实线入箭头，不看出箭头。B入箭头5个、C为4个；虚线不存在相互排斥，选A |
| 几何边界 | 点＝出现位点；边界必须同时满足覆盖、凸性、最小性 | 2023-5445919：不能只看“圈住了点”；额外外扩也不满足最小要求，选A |
| 搜索树 | 节点＝状态，边＝可走路径；回溯必须符合扩展条件 | 2025-19283926：不能补设“必须从左到右”。B沿边深入、到叶节点再回溯，选B |

对形式逻辑题也一样：**先匹配题内规定的形式，不擅自用教材中的另一种术语定义替换题干**。例如“排序推理”，本题要找的是其指定的前提—结论结构。

## 二、高频干扰项“五类伪装套路”

以下五类机制在本批反复出现，彼此可以重叠，不将其虚报为互斥的频数排名。

### 1. 主体张冠李戴、直接客体偷换

**规则①：谁做的不能换。**  
定义要求本人实施，换成机构、家属或他人实施，优先排除。

- 2024-5893535：医院建立档案、追踪指标，不等于患者的**自我管理**。

**规则②：对什么实施不能换。**  
“有助于同一目标”不能替代“直接控制同一对象”。

- 2026-19526389：员工洗手有利于药品质量，但直接管理的是人员卫生，不是各工序物料，故选C。

### 2. 必要条件缺失，用相似效果掩盖方式不符

**规则①：定义中的关键连接环节不能省。**  
出现起点和终点，不代表中间必经过程已经满足。

- 2022-4637575：转基因油菜成为“杂草”，不等于其基因已经进入其他作物或野生物种，D不体现基因污染。

**规则②：结果再好，也不能补足缺失的功能。**

- 2022-4637404：河滨公园吸引鸟类，是改善栖息条件；未体现**连接破碎生境的通道功能**，C不属于生境廊道。

反排提示：选项若只反复强调“有效、方便、改善、提高”，应回查它是否真正交代了定义规定的方式。

### 3. 范围人为扩缩、单位暗换、限定词失守

**规则①：“全部”是相对于题设总体，不是全社会。**

- 2022-4637557：调查某市所有幼儿园儿童、某省指定年级全体学生，均可在相应总体内构成全面调查，不能因范围有限就判非全面。

**规则②：只要量纲或“仅”的范围被换，就优先排错。**

- 2026-19526275：“品种数”不能换成商品数量；库存件数固定，不代表库存品种数固定。
- 2022-4639313：要求“**仅**使用司法物理鉴定”。称重后又用试剂染色，已经混入其他方法，C不能保留。

### 4. 方向颠倒、过程与结果混淆

**规则①：箭头、比值、包含关系都要按原方向核验。**

- 2022-4637373：老少比是老年人数／少年儿童人数，不是“每100名老年人对应多少儿童”。
- 2024-5893605：A→B表示A受B吸引，不能倒读成“A吸引B”。

**规则②：用了先进工具，不等于完成指定技术过程。**

- 2023-5445915：轻型直升机提高喷药效率，体现机械化作业；没有数字表达、设计、控制或管理的证据，不能据此认定数字农业。

### 5. 多定义混串交叉、只对一半

**规则①：一个显眼要件吻合，不代表整套分类成立。**

- 2023-5445814：常染色体上的性状即使只在男性表现，也不满足题设限性遗传的“性染色体”条件。

**规则②：选项给出两个标签时，必须逐个核验；一真一假仍是错项。**

- 2026-19526359：怕扣绩效属于外部动机，但不体现自主性需求，B为错误对应。

还要特别区分：

- “既属于甲又属于乙”＝同时满足两套定义。
- “甲乙均未体现”＝两套定义都不满足。
- 不能把不同定义默认成绝对互斥；有些定义存在包含或交叉关系。
