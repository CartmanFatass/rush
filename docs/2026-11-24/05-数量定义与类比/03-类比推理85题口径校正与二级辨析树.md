### 1. 编码原则

每题只给一个主标签，但不意味着该题只有一种关系：

- 三词题中的**交叉＋包含、包含＋功能、顺序＋目的**等复合关系，完整写入二级检查。
- 主标签选择**最能组织题干、最有筛选力的骨架**。
- “包含”沿用公考口径，二级再区分**种属与组成**；严格数学意义上，整体—部分不等于集合子集。
- “近义”栏兼收同义表达，避免与“全同”重复计数。

## 三、从第一眼排除到最后二选一：严格判断顺序

**严格的是判断流程与证据等级，不是让所有题都机械地“先看词性，再看感情色彩”。**不同主关系有不同的必检分支。

### 1. 总流程

| 顺位 | 必做动作 | 可以排除什么 | 禁止的做法 |
|---|---|---|---|
| **0** | 校验题型与材料归属 | 非类比题、误挂背景 | 把排班题的先后关系统计为类比“顺序” |
| **1** | 确定完整词语的常用义与对象类别 | 望文生义、词义误认 | 一上来就任意拆字 |
| **2** | 固定项位，建立完整关系图 | 方向反了、只匹配局部 | 填空题把右侧顺序倒置；三词题只看前两词 |
| **3** | 判定一级骨架 | 集合、作用、词义、语法之间的错配 | 用“都有关”“都能导致”包办全部关系 |
| **4** | 执行该主类的必检二级项目 | 种属／组成、链式／双因等结构差异 | 一级未匹配，就凭一个冷知识选答案 |
| **5** | 比较关系的稳定性与直接性 | 偶然用途、间接联系、临时场景 | 为选项补人物、补情境、补安排 |
| **6** | 检查对象、主体、功能地位与内部结构 | 主体模式不同、褒贬反向、词性结构不同 | 将不影响区分的细枝末节无限加码 |
| **7** | 最后二选一：选择额外假设最少者 | 依赖特殊口径或特殊情境者 | 为追求“绝对同构”否定唯一明显最佳项 |

### 2. 一级主关系如何划分

不要把四类理解成必须依次尝试的优先级。应先问“题干主要在比较什么”。

| 识别问句 | 主类 |
|---|---|
| 能否用“是同一类／是其中一种／是一部分／既是甲又是乙”准确表达？ | **外延集合** |
| 能否用一个明确谓词连接，如“导致、用于、为了、制成、发生于、先于、具有”？ | **内涵对应** |
| 主要比较的是词义相近、相反，或本体与喻体的意义映射吗？ | **语义关系** |
| 外部语义关系很弱，但内部组合方式稳定重复吗？ | **语法结构** |

特别注意：**“逐客令—挡箭牌”不能只停在“都是比喻词”**。真正有辨识力的是内部“动宾＋名词中心语”。

### 3. 各主类内部的下探顺序

#### A. 外延集合

**关系形状 → 包含方向 → 种属／组成 → 分类轴 → 矛盾／反对 → 层级粒度**

- **种属**：“甲是一种乙。”
- **组成**：“甲是乙的一部分。”
- **交叉**：有重合，但双方都不完全包含对方。
- **矛盾**：在明确全集和同一标准下，互斥且穷尽。
- **反对**：互斥，但还存在其他类别。

典型检查：

- “铜镜—化妆镜”：不仅交叉，还要求**材料分类→用途分类**，因此选“木碗—汤碗”。
- “自发裂变—核裂变—诱发裂变”：不仅前后属于中间，还要求**前后穷尽中间**，对应负有理数、负无理数与负实数。
- “光伏电站—电池板—发电”：第二项是组成部分，第三项是**整体功能**；不能额外要求该部件单独完成整体功能。

#### B. 内涵对应

按具体子关系分支：

| 子关系 | 二级优先顺序 |
|---|---|
| 因果 | 因果方向 → 链式／双因一果 → 直接性 → 主体与结果性质 |
| 目的 | 手段与目标方向 → 提升／保持／抑制 → 工具、操作、目标的角色 |
| 功能 | 本职／主要功能 → 辅助／偶然用途 → 使用对象及实现主体 |
| 材料 | 原料—成品方向 → 材料／部件／工具区别 → 加工或反应角色 |
| 场所 | 活动—场所方向 → 专门、制度性对应 → 一般可发生地点 |
| 顺序 | 次序是否成立 → 工序／结果／目标区别 → 主体模式 |
| 属性 | 属性归属 → 指标或性质类别 → 稳定属性／偶然状态 |
| 数量 | 先写等式 → 核对项位 → 核对量纲与统计口径 |

三个不能混淆的界限：

1. **目的不是必然结果**：“军事演习”为提高作战能力，不等于每次演习都必然提高。
2. **通常因果不是充分条件**：“贸易摩擦”可能导致出口下滑，不意味着有摩擦就必然下滑。
3. **专门场所不是唯一物理地点**：“质证—法庭”优于“采访—现场”，但不能据此断言不存在远程庭审。

#### C. 语义关系

**义核 → 近反义或比喻机制 → 使用对象 → 感情色彩 → 程度、语体**

- 先看真实含义，不能只找共有字。
- “殚精竭虑—费尽心机”的重点是**相近行为义核＋褒到贬**。
- “珍珠—珍珠婚”与“母亲—母亲河”重在品质、作用联想，不是外形相似。
- “花海—书山”还要检查**本体在前、喻体在后**。

词性要检查，但**不能机械要求题干与答案使用完全相同词性**。例如“一望无垠—辽阔”与“耳提面命—教导”，核心是成语与解释词的近义对应。

#### D. 语法结构

**整体句法 → 内层结构 → 中心词词性 → 主体与动作逻辑**

重点有三种：

- `载＋歌／载＋舞`：同一主体的并列动作。
- `明辨＋是非／静待＋成败`：动宾结构，宾语内部又是反义联合。
- `[逐客]＋令／[挡箭]＋牌`：外层偏正，内层动宾。

### 4. 本样本中需要保留的边界

这几题尤其能防止“二级辨析过度”。

- **2023-5445816**：匿名／实名通常可作穷尽划分，早间／午间则不穷尽全天；但 A 是唯一匹配“前两项并列、第三项分别与之交叉”的选项。不能让一个非完全一致的细分维度推翻完整结构。
