### 3. 政治理论独立后，究竟剩下什么？

#### 核心结论：形成“法—科—地”主轴，但不能理解为只剩这三科

2025—2026年共53题：

| 板块 | 题数 | 占比 |
|---|---:|---:|
| 法律 | 15 | 28.3% |
| 科技与国之重器/物理化生 | 15 | 28.3% |
| 地理国情 | 11 | 20.8% |
| 人文历史/古诗词/民俗 | 5 | 9.4% |
| 生活与应急常识 | 4 | 7.5% |
| 经济宏观/财税政策 | 3 | 5.7% |
| **合计** | **53** | **100%** |

**法律、科技、地理合计41题，占77.4%。** 合并期这三板块为50/75，约66.7%，样本内集中度确实提高。

可以收敛到以下主题：

1. **法律：基本制度＋新修法中的适用边界。**  
   合同与善意取得、行政复议、消费者保护、公司公示，以及监察、反洗钱、政务数据等制度。重点不是逐条背法，而是识别**主体、条件、程序、例外**。

2. **科技：基础原理落入具体场景。**  
   力学、电学、光学、化学平衡、生物分类、材料性质，包装成温室、船只、汽车、海洋产业、考古技术等场景。

3. **地理：天文地理＋中国区域与生态资源。**  
   昼长与纬度、星体身份、地质年代、盆地成因、河流湖泊、荒漠化、农业区划及运输条件。

4. **小而稳定的补充：基础人文、健康医学、宏观财税。**  
   历史大顺序、人物作品、医学检查原理、税种对象及政策工具用途。

**两项战略修正：**

- **不能把早期“国之重器”热度直接外推。** 本样本2025—2026年没有航天器命名分工题；科技增多主要体现为原理、材料和应用技术，而非装备名录。
- **不能说剩余常识的题量在本样本中缩水。** 去重后年度题数为24、26、25、25、28，未显示数量下降。缩水的是部分政治知识边界，集中的是知识结构；同年三套卷去重数量也不等于单套试卷题量。

### 2. L1：应当形成的可复用底层判据

| 判据 | 最小规则 | 本样本落点 |
|---|---|---|
| **公权力的主体与授权** | 先问“谁有权”，再问“能做什么”；部门、层级不能随意替换 | 县级人大立法权、行政拘留主体、行政强制设定 |
| **程序权利不等于自动启动** | 有听证权，不等于机关在任何情况下都必须实际组织听证 | 2022-4637187 |
| **内外部行政行为分开** | 面向行政相对人的管理行为，与机关内部人事处理不是同一救济轨道 | 2025-19283889 |
| **处罚、犯罪须满足构成要件** | 不能因“看起来违法”就套最熟悉罪名；身份、目的、事实基础均要匹配 | 利用影响力受贿、虚假诉讼、伪证 |
| **合同效力与物权变动分开** | 无权处分不当然使合同无效；登记也不自动消除合同的撤销事由 | 房屋买卖、拍卖、善意取得 |
| **所有权与使用权分开** | 承包不是取得土地所有权；继承取得与交易登记规则不同 | 2025-19283835 |
| **补救不能制造二次损伤** | 腐蚀性物质、热水促吸收、大量饮水等，都要检查是否加重伤害 | 2022-4637196 |
| **货币与财政先分工具，再判方向** | 央行卖债通常回笼资金；逆回购通常投放资金；减税通常不是紧缩工具 | 2022-4637181、2024-5893790 |
| **税种看征税对象，不看“都与钱有关”** | 资源开采、污染排放、消费行为、所得分别对应不同税收逻辑 | 2026-19526348 |
| **公式必须连同条件记忆** | \(I=U/R\)需电阻条件；浮力看排开流体体积；胡克定律有弹性限度 | 2025-19283884 |
| **能量、作用对象与变化层级** | 下坡重力势能下降；力成对作用；核反应不是化学反应 | 船只行驶、核裂变 |
| **化学变化看反应机制** | 分解不等于复分解；酸碱影响平衡；金属容器不必然适合储存腐蚀性物质 | 石灰石、肥料、化学平衡 |
| **生物生产看收支** | 光合作用积累有机物，呼吸消耗；适度降夜温、补充二氧化碳有条件地有利 | 温室栽培 |
| **地理现象必须与空间、季节相容** | 北半球夏季昼长一般随纬度增加；南北气候约束不同农业措施 | 日月升落图、农业规划 |
| **统计关系不自动升级为因果** | 高相关不证明因果；预测模型也不等于因果解释 | 2024-5893826 |

其中几个尤其值得“跨题连线”：

- **2024房屋善意取得 → 2025自行车善意取得**：换了物，核心制度不变。
- **2022货币政策 → 2024逆回购**：换了工具名，仍是资金投放与回笼。
- **2025力学比例关系 → 2026数学符号时钟**：都要求核验公式、量纲及适用条件。
- **2023南北农业措施 → 2026运输方案**：都应先检查气候与空间可行性。

> 急救题中的拟答仅是对原题的判断，不应转化为自行服药、催吐或洗胃指引；真实中毒、烧伤应及时寻求专业救助。

#### 考场猜排的底线

可以利用的，是**逻辑负担**，不是“神奇选项学”：

1. 找出一个选项中被捆绑的多个断言，逐个拆开。
2. 检查是否省略条件、偷换对象、把局部说成全体。
3. 有最小锚点时再排除；没有事实依据时，只标记可疑，不冒充已证伪。
4. 真正四项对称、又无知识锚点时，承认无法靠结构提高判断力。

**不能据本盲测声称“选绝对词能提高多少正确率”**；尚无答案核验及对照试验。也不使用答案字母均衡、选项长短、陌生度等猜题规则。

### 怎样把这些Pattern变成操作？

对每个选项依次问：

> **谁？对什么对象？在什么条件下？实施什么行为？产生什么结果？**

- 法律题，优先拆**主体—权限—程序—例外**。
- 科技题，优先拆**对象—机制—方向—适用条件**。
- 人文地理题，优先拆**身份—年代—位置—功能**。
- 政策题，优先拆**目标—工具—直接支持对象**。

绝对词只负责提示核验，不负责裁决。例如“只能由法律设定”在法律保留事项中完全可能正确；不能见“只能”就排。
