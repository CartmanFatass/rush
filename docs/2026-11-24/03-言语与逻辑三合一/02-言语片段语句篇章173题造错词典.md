## 二、干扰项“造错词典”：五维排错

### 1. 主体/对象偷换

**造错操作：保留谓语，替换谁在做、作用于谁、研究的是谁。**

| 代表题与选项 | 原文关系 | 选项如何造错 |
|---|---|---|
| 2022-4637240，D | **集体经济组织**整合资源，再加入专业合作社 | 将整合资源的主体换成**专业合作社** |
| 2024-5893708，C | 冷冻干燥后，相关网格结构发生形变 | 换成**不饱和脂肪酸**发生形变 |
| 2026-19526296，B | 半规管感知气压变化，再传给前庭神经 | 把**传递环节**换成最初感知主体 |
| 2025-19283989，D | 医生因玩有毒颜料上色的纸牌而不适 | 把人物职业“医生”偷换成应用领域“医疗” |

**排错动作：先圈名词，再核动词。**  
尤其核对：研究者/使用者、原料/成品、组织/器官、机制/结果、个体/群体。

### 2. 因果/条件/时间时态反转

**造错操作：把箭头倒过来、把条件拿掉、把研究阶段提前。**

| 代表题与选项 | 原文关系 | 选项如何造错 |
|---|---|---|
| 2024-5893710，B | 案情复杂、定性困难等 → 多环节行刑衔接 | 写成行刑衔接**导致**复杂状况，因果倒置 |
| 2022-4639343，B | 感染弓形虫是老鼠不怕猫的一个情形 | 写成“**只有**感染才不怕猫”，强加必要条件 |
| 2024-5893702，C | **概念验证实验**展示治疗能力 | 升级为已在**临床**验证 |
| 2023-5445891，C | 九日山祈风石刻属于**宋代** | 替换成**唐代** |
| 2023-5445728，D | 行星在原行星盘存在阶段获取物质 | 不保留阶段条件，写成持续不断获取 |

**硬规则：**

- “只有A才B”是 **B→A**，不是A→B。
- “A可以导致B”不等于“B只能由A导致”。
- **概念验证≠动物验证≠人体临床≠普遍有效。**
- “过去如此”“目前如此”“未来可能如此”不得互换。

**造错操作：改量词、概率词、程度词、适用范围。**

| 2026-19526318，B | 近域宇宙中**大约一半**被观测星系息产 | 扩成**大多数**星系 |

## 三、排序与接语题：“3秒锁定锚点规则”

这里的“3秒”指**快速发现可排除选项的锚点**，不是保证三秒完成所有题，更不是实测速度结论。

### 1. 排首禁区：禁的是“依赖前文”，不是某个词本身

| 信号 | 可直接利用的规则 | 边界与代表题 |
|---|---|---|
| “这、这些、其、该、上述、这种” | 若没有句内先行词，通常不能独立起首 | 2023-5445697：“这些病态的软骨细胞”必须先有病态细胞形成 |
| “同样、此外、也、甚至、因此” | 查找比较基准、并列前项、递进基数或原因 | 2023-5445695：①“同样”需承接④的另一种优势 |
| “但是、然而” | 必须有可成立的转折对象 | 2024-5893706：⑤过去监测方式→①“然而”指出局限 |
| 背景、定义、时间起点 | **可以起首，不是起首保证** | “过去、近年来、随着……”都可能居首或承上 |
| 引语、实例、数据 | 不可一概排除起首 | 2023-5445901正确顺序以②诗句实例开头 |

### 2. 强捆绑优先于“读起来顺”

| 锚点类型 | 捆绑方法 | 代表链 |
|---|---|---|
| 名词引入→指代复现 | 先出现对象，后出现“它/这一类群/这些细胞” | 2022-4637233：③发现新类群→⑥“这一新类群” |
| 状态变化→后续机制 | 顺着“发生什么—造成什么—进一步怎样” | 2023-5445697：③病态形成→⑤细胞凋亡→⑥凋亡小体矿化→①病情恶化 |
| 术语→定义→定义再解释 | 定义链不能随意插入历史材料 | 2026-19526401：③爱因斯坦→⑤单铺砌块→①非周期性 |
| 一般程度→更高程度 | “甚至”通常承接较低程度基准 | 2024-5893831：⑤提高1倍以上→③甚至提高3～4倍 |
| 问题→原因→应对 | “因此、为此”后应承接可解决的问题 | 2023-5445825：④射线干扰→②建地下实验室→①四川实例 |

**注意：前后关系不一定等于紧邻关系。**  
只有指代对象唯一、解释连续、选项差异又恰在相邻位置时，才升级为“紧密捆绑”。

### 3. 三条顺序线

- **时间线**：早期→后来→当前。  
  2025-19283851：天然材料即可满足→绝缘材料独立→环境要求提高→组合结构开发。
- **空间线**：按原文给出的观察、运动或布局顺序排列，不能自行发明“由远及近”。  
  2026星状沙丘材料中的“基部—上方—触手—西侧”，用于追踪年代和迁移证据。
- **逻辑线**：总类→子类；定义→机制；证据→判断；问题→措施。  
  2026-19526273：火星风沙地貌→横向风成脊→研究意义→测量发现→古风向判断。

### 4. 下文推断：尾句不是只看最后几个字，而是看“尚未兑现的写作承诺”

| 尾部状态 | 下文优先方向 | 代表题 |
|---|---|---|
| 刚提出一个新对象，尚未介绍 | 展开该对象的研究或特征 | 2023-5445703：杨氏鱼→最新研究 |
| 刚说“存在诸多障碍”，未列举 | 优先解释障碍，而非立刻跳解决方案 | 2024-5893707：版权保护困境 |
| 问题及危害已经展开 | 转入解决路径 | 2025-19283912：冻土荒漠化→防治措施 |
| 已论证某机制/制度有价值 | 转入如何实施、如何发挥作用 | 2024-5893725：适老诉讼→建设路径 |
| 已指出关键在获取某类信息 | 转入获取方法 | 2023-5445838：恒星信息→获取途径 |
| 已详述致病传播机制 | 转入干预传播的办法 | 2026-19526447：致病蛋白传播→阻断手段 |

### 5. 最短执行链

> **扫选项首尾差异 → 找两条最强依赖边 → 排除冲突选项 → 回读唯一候选的转折、指代和结尾。**

接语题额外删三类选项：

1. **前文已经讲完的重复内容**；
2. **只与全文主题有关、却接不上尾段的泛话题**；
3. **跳过必要中间环节的过远推断**。
