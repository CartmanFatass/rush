## 阅读说明：本报告的统计口径与判断边界

本报告不使用参考答案或官方解析，按题干、选项及相关基础知识独立判断。需要先明确四点：

1. **知识层、备考层、设错类型是三个不同维度。**  
   来自中央会议的题，也可能只考一个应长期保存的基础对应关系；专项法规中的冷门细节，则不一定值得进入最小必背集合。

2. **“选项错误”不等于“选项中的陈述错误”。**  
   反向选择题的正确答案，通常是错误陈述；“不属于”题的其他选项可能全部真实。本报告分别判断陈述真伪、题域归属和最终答案。

3. **“复合题”按知识结构识别，不冒充已经核实的文献拼接事实。**  
   题面通常不能证明四个选项究竟摘自几个外部文件。因此，下文的“跨出处复合层”是跨年代、跨制度或跨场景的结构性分类；不能据此断言存在同等数量的“多文件剪贴题”。

4. **有两项需要特别保留核验标记。**
   - **2026-19526238：暂判C。**争议在④。“自力更生是中华民族的优良传统”与“独立自主是我们立党立国的重要原则”均有常见固定表述。题中将“独立自主”同时接到两个判断上，疑似固定表述移植。但仅从宽泛语义看，不能严密证明④必假。若按概念兼容而非固定表述判断，可得到D。**待核原文，不能把暂判冒充无争议答案。**
   - **2025-19283768：暂判C。**按①—④正确、⑤错误处理。其中④“风光火核储”的完整配置应核对原文，不能凭“不常见”就擅自删掉“火”“核”或判错。

以下计数均按这套明确的暂定判断闭环。除题面已经列出的文件、会议名称外，不补造具体发布日期和唯一出处。文中的纠错主要是**概念还原，不冒充逐字引文**。

### 1. 分类规则

采用五个互斥知识层：

| 知识层 | 判定标准 |

### 3. 单靠考前刷近期热点，会漏掉多少？

不能把“来源层级占比”直接转换成“漏题率”。原因是：

- “近期”没有统一时间窗口；
- 基础理论也可能在近期讲话中重述；
- 科技、考古事实同样可能成为近期热点；
- 读过某份文件，不等于掌握了选项所考的精细关系。

但可以给出两项**可复核的结构指标**：

#### 指标一：不应交给年度热点替代的基础盘

**24/77＝31.17%**属于基础理论与党史层。

这一比例说明：若复习体系没有长期理论底座，而把全部知识都按“今年出了什么文件”组织，至少有约三成样本没有获得稳定、系统的复习位置。

这不是说这24题绝不出现在热点材料中，而是说它们**不应该依赖偶然刷到热点来掌握**。

#### 指标二：超出单一顶层/专项文件主线的知识结构

基础理论与党史、跨出处复合、跨学科事实共：

$$
24 + 5 + 6 = 35\text{ 题，占 }45.45\%
$$

因此，若所谓“刷热点”仅指记住近期会议、文件的标题与摘要，它对这**45.45%样本的知识结构不构成充分覆盖**。

另一方面，即使余下42题都归入顶层论述或专项文件，也不能认为它们都是“考前短窗口新文件”：

- **2022-4637422**题面明确引用2020年会议；
- **2023-5445939**考2021年条例；
- **2024-5893560**考2022年施行的法律；
- **2024-5893579**继续考党的二十大报告。

**结论：真正危险的不是“不追热点”，而是用热点目录替代长期知识库。**

## 二、选项设错 Pattern Taxonomy

### 1. 编码原则

设置八类内容设错，以及一类题型结构风险。

- 同一道题可有1—3个标签。
- JSONL中`trap_types`的**第一项为主模式**，其余为次模式。
- 主模式每题只计一次，合计77题。
- “命中题数”允许重叠，不应相加当作总题数。
- 数量题统一附加“组合计数误判”；它是答题结构风险，**不是说其中所有原子判断都有问题**。

这里统计的是**题级命中频率**，不是把每道题的三个干扰选项当成三个独立样本。

### 4. 每类代表题：逐项拆解

#### P1：主体或对象错配

**代表一：2024-5893765，答案D**

- ①排污许可、自然资源资产管理、国土空间用途管制：正确。
- ②财政、税收、金融、价格支持：正确。

- A、B、C均包含④；D为①②③。

**代表二：2026-19526276，答案C**

- A：“经济发展需求”不足以替代科技战略部署所面向的国家战略需求，缩窄了目标范围。

- C：科技领军企业、中小企业、民营企业及国家重大科技项目之间的关系正确。

**秒判要点：**先圈主语，再圈谓语。不要因“人才、政府、创新”等词都重要，就默认可以互换角色。

## 三、三层集合与“知识保存粒度”

### 1. 三层分布

这里按**本题的决定性作答知识应放在哪一层复习**分类，而不是说整道题涉及的每个细节都必须同等背诵。

| 备考层 | 题数 | 占比 | 功能 |
|---|---:|---:|---|
| **L1 最小确定集合** | **46** | **59.74%** | 跨年复用的理论关系、固定组、价值落点与基本辨错结构 |
| **L2 泛化概念集合** | **20** | **25.97%** | 滚动更新会议、文件、治理部署的结构化母体 |
| **L3 Outlier** | **11** | **14.29%** | 低复用事实、细密条款、短期排名与地方对应 |

注意：L1有46题，并不意味着只背一个短清单就能无条件拿下46题。它表示这些题的**主要决胜知识具有长期保存价值**。

### 2. 第一层：最小确定集合——稳态底线

建议按六个模块保存。

#### 模块A：世界观、认识论与历史观

至少包含：

- 人民群众是物质财富、精神财富的创造者；
- 实践与认识、理论创新的关系；
- 实践的客观物质性、能动性、社会历史性；
- 矛盾普遍性与特殊性；
- 真理尺度与价值尺度；
- 马克思主义是方法，不是僵化教条。

**保存粒度：**

```text
概念 → 核心定义 → 相邻概念区别 → 最易倒置的一条关系 → 一个反例
```

例如：

```text
实践 → 能动改造世界的活动
区别 → 不是无目的本能活动；不等于单纯认识活动
关系 → 实践是正确发挥主观能动性的根本途径
反例 → “正确发挥主观能动性是实践的根本途径”
```

对应2025-19283724、19283746、19283767，2026-19526337、19526341等。

#### 模块B：政治经济学与经济治理基础

至少包含：

- 具体劳动—使用价值；抽象劳动—价值；
- 社会必要劳动时间—价值量；
- 市场决定性作用—政府更好发挥作用；
- 供给、内需、外需的直接政策指向；
- 初次分配、再分配、第三次分配；
- 创新、协调、绿色、开放、共享各自解决什么问题。

**关键不是背定义，而是能区分相邻制度。**

2025-19283722与19283967说明：一条政策可能真实、合理，却不属于题目指定的制度或政策域。

#### 模块C：长期政治与制度对应组

优先保存：

| 对应组 | 主要防错位置 |
|---|---|
| 法治国家、法治政府、法治社会 | 目标、主体、基础、引领与示范 |
| 党性、党风、党纪 | 根本、表现、保障 |
| 党的建设总体布局 | 统领、根基、主线、着力点 |
| 就业、健康、社会保障、分配制度 | 最基本民生、强盛标志、安全网、基础性制度 |
| 统一战线、人民军队等 | 重要法宝、战略支撑等定位 |
| 自我革命相关要求 | 根本目的、战略目标、主攻方向、动力 |
| 战略与战术 | 全局性长期性安全与具体数量问题 |

本样本P3主模式达19题，是最值得形成**整组检索卡**的部分。

#### 模块D：阶段与目标时间轴

至少分清：

- 社会主义初级阶段与新发展阶段；
- 全面建成小康社会、基本实现现代化、建成现代化强国；
- 2035与本世纪中叶；
- “进入行列”“进入前列”“基本实现”“全面实现”；
- 新民主主义革命与社会主义革命的成就边界。

**保存粒度不是“2035”一个数字，而是：**

```text
时间 → 主体/领域 → 目标内容 → 实现程度 → 不属于本阶段的目标
```

#### 模块E：人民立场与最终评价标准

保留以下“落点辨析”：

- 政绩不等于数据、排名、工程气派；
- 现代化不等于纸面指标；
- 文化强不等于服务产品数量或生产能力；
- 农业强不等于单一扩大耕地面积；
- 高质量发展不等于总量、规模取胜；
- 人口高质量发展不等于高速增长。

这组知识能跨会议、跨年度迁移，对应P6的15题命中。

#### 模块F：八类内容错误的反向训练

每个知识点至少能主动造出一个错误版本：

- 换主体；
- 反箭头；
- 换槽位；
- 改年份或程度；
- 增加强制词；
- 用手段替代目标；
- 把真实政策移入错误题域；
- 交换人物、地点、事实属性。

**能够解释“错在哪里”，比认得一句正确原文更接近考试要求。**

#### 分成三类处理

| 类型 | 样本 | 合理策略 | 不建议投入 |
|---|---|---|---|
| 跨学科事实 | 珠峰测量、航天、古诗、矿产、考古 | 维护高辨识度人物—事物—属性卡 | 顺着一题扩展成整部科技史、文学史 |
| 精细法规 | 党徽党旗、黑土地占用例外 | 重点保留强制程度、例外、禁止行为 | 无筛选逐条背整部法规 |
| 精确排名或场景对应 | 研发排名、地方考察对应、名句时序 | 限定少量高识别锚点，定期校验时点 | 永久背所有排名、所有省份每次讲话 |

#### 止损规则

1. **孤立事实只保存能直接形成选项判断的最小配对。**  
   如“雪深雷达—电磁波”，不必扩展整套测绘技术流程。

2. **易变事实必须带时点。**  
   “世界第几”“最大矿”“首次”不可脱离时间永久记忆。

3. **条款优先记边界，而不是平均记忆全文。**  
   “可以/应当/必须”“原则/例外”比大量一般性条文更容易成为改错位置。

4. **存在争议的措辞进入核验队列，不强行制造确定性。**  
   2026-19526238就是例子。没有原文，不应把近义表达机械判成知识错误后反复背诵。

5. **L3不等于放弃。**  
   本样本不少L3题可凭高辨识度选项排除；低性价比的是无限扩展记忆范围，而不是做完真题后的有限补漏。

## 四、研究结论

这77题呈现的主要命题规律可以概括为：

1. **出处在更新，设错结构高度稳定。**  
   年度文件提供素材，主体、方向、固定组、阶段和评价落点提供主要出题接口。

2. **“词都认识”不等于掌握。**  
   高频错误不是生僻概念，而是把熟悉概念放到错误位置。

3. **单纯近期热点复习缺少两种能力。**  
   一是覆盖基础理论与历史制度的长期知识；二是识别熟悉句子中的微小结构改动。

4. **跨文件复合的真正要求是可迁移的知识索引。**  
   不能只按“文件A第几段”储存，还要能按“主体、主线、首要任务、目标年份、转型方向”检索。

5. **最有效的知识保存单位，是带边界的关系。**  
   即：  
   **谁—做什么—作用于谁—朝哪个方向—达到什么程度—最终用什么评价。**
