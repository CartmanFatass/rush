# 任务书（第三版）：从真题里查，不要意见

前两版任务书问的是"这部分考什么能力""各部分共用什么能力"，得到的是谁都知道的教学常识。这一版不问看法，只要从真题里数出来、查出来的东西。

## 交付什么

一组"发现"。每条发现必须同时有下面五项，缺一项就不要写这条：

1. **发现**：一句话，带数字或题号。例："2024–2026 年副省级言语片段阅读 45 题里，正确选项与文段尾句同义的 N 题，与转折后一句同义的 M 题。"
2. **证据**：逐题清单。每题写年份、卷别、题号，并引用题干、选项或材料里的原文（不转述）。
3. **它检验了哪条通行说法**：例如"主旨在尾句""转折之后是重点""选项越绝对越错"。写明成立、不成立，还是只在某类题成立。没有对应说法就写"无"。
4. **在一道题上演示**：从清单里挑一道，写出按这条发现做题时每一步看哪里、划掉哪个选项、为什么。要让没见过这条发现的人照着能做第二道。
5. **反例**：不符合这条发现的题号，至少查过才能写"无"。

## 不要什么

- 不要能力归纳。去掉题号和数字后仍然成立的句子都删掉，例如"要准确理解材料""言语和申论共用定位能力"。
- 不要学习建议、学习顺序、时间安排、提分估计，不对考生水平作任何假设。
- 不要引用培训机构的方法论当依据。机构解析只用来确认答案，结论从题目本身数出来。
- 不写"必考""押题"。

## "联系"怎么写

只接受指到具体题目的对照。例："2026 副省政治理论第 X 题的错误选项把'基础性'换成'决定性'，同卷言语第 Y 题的错误选项把'部分'换成'全部'，都是换范围词"，两边都要引原文。查过没有就写"没有找到"，这也是有用的结果。不要写"两者共用某种能力"。
