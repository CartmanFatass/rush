# 最后12天备考建议

**推荐：【推断】立即从“继续生产资料”转为“限时作答—定位失分—回查资料”，优先补上行测其他模块的诊断。**按背景题量，政治理论之外还有115题；不了解这些题的正确率和耗时，就无法证明当前投入最划算。“没分析过”不等于考生不会，但值得先测，不能继续默认政治理论优先。

标记说明：【事实】指已读文件可核对的内容，不等于官方评分结论；【推断】是我的判断或条件性目标；【经验】是一般训练建议。以下改善幅度不是提分承诺，各项不能相加。

核查边界：【事实】已读三份手册、原理卡、统计报告，抽查2022、2026副省级申论及2026政治理论前五题。大作文手册确有缺节（`申论手册/03-大作文.md:51–53`），未核验背景中的2026年新闻节点和考试日程；以下沿用所给12天窗口。文中“手册01/02/03”分别指三份申论手册。

## 一、时政（行测政治理论20题）

**最值得做：**
1. 【经验】用已有三张卡做闭卷辨析：先说概念、主体和对应关系，再看原文；错项隔一天重测。六个必须坚持都复习，不只学尚未单独考过的条目。每次只收进真正混淆的句子。【推断】若当前20题约对10—13题，12天以同难度陌生题多对1—3题为保守目标；主要来自减少已学知识的混淆，不是扩大阅读量。
2. 【经验】做两组未见政治题，给每个判断标“知道／排除／猜测”，复盘猜对题。原理薄弱就用现成简明讲义补实践、矛盾和劳动价值等基础，不从头学教材。【推断】目标是把反复错的2—3组概念变成隔日仍能解释；若本已稳定16题以上，改为维持，不增加时间。
3. 【推断】剩余专题先用一份可靠年度提纲扫盲，只对做题暴露的缺口查官方原文；近期重要文件读主旨和核心提法即可。收益是减少整块陌生，具体能转化几题没有依据。

**应停：**【推断】暂停补齐九张精细卡、逐篇溯源和宣传热度统计；这些适合研究，不适合现在的记忆预算。不要因报考金融监管而扩大公共科目金融专题。

**结论须降级：**【推断】74题跨卷可能重合，讲话又会重刊，首次提出、重刊和解析引用不能混为命题时间。全会几个样本推不出“四个月界线”；未考条目不因此更可能考。最应撤销的是原理卡“找不到改动就按全对”（`素材库/01-原理与方法论.md:204`）：一道全对题不能支持猜题规则。该卡称“官方解析”，但`README.md:46`明确材料是回忆与机构复盘。

**还缺：**【经验】缺的是闭卷错因记录、原文出处和未见题，不是更长的卡；涉及“管得住／管得好”须连同文件和时间记，不能把旧表述一律判错。

## 二、行测其他模块

**最值得做：**
1. 【经验】第一天做对应卷别120分钟整卷，包含涂卡。记录各模块作答数、正确数、耗时，区分知识不会、会但太慢、审题计算错。随后只选两个最可修复的弱项。【推断】诊断本身不保证加分，但可避免把数小时投进已稳定模块或短期补不动的难题。
2. 【经验】若无诊断依据，先试资料分析和判断推理：资料重点查找数、单位、基期现期、增长率与比重，练估算前先判断误差是否影响选项；判断按图形、定义、类比、逻辑分别定位，禁止整块平均刷。【推断】若每组20题里有3—5题属于这些可修复错误，目标是在陌生同类题少错2—3题；两次练习无改善就换目标。计算机背景不能替代测量。
3. 【经验】言语练“结论所据句子”和选项差异，不临时背大词库；数量保住已会的基础题，先识别再决定做不做，别整块放弃；常识只复习已有错题。用第二、第三次整卷验证跳题时点及各模块时间上限。【推断】若原来末尾大量空白，回收5—10分钟可能比学新技巧更有效；具体多对几题取决于留下的题。

**应停：**【推断】停止给五个模块另做文献分析、全课程补课和偏难数量专题。三次整卷够作诊断与验证，重点是复盘，不是每天刷一套。

**对已有方向的质疑：**【事实】背景没有模块成绩。【推断】因此既不能认定其他模块已稳，也不能认定政治比资料分析更好提分；题量更大只说明应诊断，不自动决定最终分配。行测各题权重不明，不把“多对几题”机械换算为分数。

**材料怎么用：**【事实】仓库整卷选项直接标正确答案（`README.md:35`）。【经验】必须先遮蔽标记和解析，再测；看过答案的卷只用于复盘。还缺的是干净试卷、计时数据和一张个人跳题清单，无须补建题库。

## 三、申论大作文

**最值得做：**
1. 【经验】选4—6道题，只练10—12分钟审题提纲：解释核心词、限定条件、中心判断，再检查分论点是否分别推进论证。优先用陌生真题，不练预测题眼。【推断】目标是减少一次漏条件或三个分论点同义反复；对原本偏题者价值大，对立意已准者收益有限。
2. 【经验】共手写3篇，其中2篇放进整卷。先按60—65分钟试写，再凭实际速度调整；每篇只重写最弱的一段，检查“事实如何支持判断”，不是只加“因此”。【推断】先实现连续两次在预算内写满规定字数、论点扣题、主要段落有分析；无官方评分和可靠批改，不能诚实承诺涨几分。
3. 【经验】从已有真题熟悉的乡村、企业、公共服务案例里各留少量可准确复述的事实，能说明机制和条件即可。范文只比较同题两篇的立意及论证，不背整篇。【推断】预期减少临场搜例子和编事实的时间，而非靠名言增加分数。

**应停：**【推断】暂停跨题范文大汇总、为所有关系预制文章、另攒热点论据。已有手册第五节的审题动作和自查清单够用，不等缺节补齐才练。

**结论须降级：**【推断】“10题都可解释成关系型”是有用的教学归类，不是命题边界；不能强把所有题写成“A重要、B重要、结合重要”。手册03把“少于两则材料”判成未参考资料（第243行），是自设门槛；联系实际也不等于强塞材料外名人案例。第61行规定35分钟写千字，对未测书写速度的人风险很大。

【事实】`analysis/REPORT.md:278`仍按热度与距上次出题年数排序，第306行又承认语料构成逐月变化。【推断】近邻不等于来源，相关性降低也不能证明命题主动避热点；两者都不足以指挥最后12天选题。

**还缺：**【经验】最缺个人限时成稿和基于题干、材料的反馈，不是第三篇范文。若无人批改，用同一清单隔日复核，分数不要自行估得过细。

## 四、申论其他题

**最值得做：**
1. 【经验】练6—8道独立小题，覆盖概括、解释评价和对策。先圈任务、对象、材料范围及分类，再取点合并；复盘逐条标材料出处，区分漏读、漏任务和压缩失真。【推断】若目前常漏整类内容，目标是每题少漏一个关键类别，比追求八字标题更可控；不是保证每题固定加几分。
2. 【经验】对策按“问题—材料已有办法—可行措施”核对；分析题先回答判断，再给理由和条件，不把所有题当摘抄题。【推断】预期消除答非所问、建议无对象等低级错误。手册01的材料映射可用，短语密度不能当评分表。
3. 【经验】独立写3篇应用文，覆盖对上汇报、公众动员、短评；其余文种只审题列纲。检查身份、读者、目的、人称和时态，短评要有判断与理由。【推断】目标是从“材料缩写”变为完成指定任务；两套整卷内再验证字数和用时，独立练习不重复占预算。

**应停：**【推断】不照搬三份手册各自的12天课表，也不按“每50字一条”硬凑条数（手册01第295行）。停止把答案措辞一致率当分数，数字和专名也不能一律删除：若本身回答任务就应保留。

**明确纠错：**【事实】“每卷固定一道约20分问题＋对策”不成立：2022副省第二题为15分，问已经如何解决，不要求新提建议（`申论/2022国考申论（副省级）.md:129`）；手册01第58行已说明。【推断】必须按当题任务训练，不能套固定配方。应用文题干未写“格式”，不证明格式没价值；机构答案有无落款不一，也不足以推出普遍可省（手册02第144行）。按文种和题干保留必要要素，不编日期、发文机关。

**材料及缺口：**【事实】手册01第87行记录30份答案中10份超字数。【经验】已有手册用来查错、比要点来源，不全文背诵；意见冲突时回题干和材料裁决。最缺的是本人在格子纸上的答案及超时、超字数记录。

## 五、时间怎么分

【推断：假设】考生有基础、尚未形成稳定速度；每天公共科目可用6小时，已另留专业科目时间。先核实岗位卷别和官方考试安排，不凭报考部门推断。以下按11月16—27日训练；已熟题换为未见同卷别年份，跨卷只补题型。

【经验】公共科目总预算：**政治15%、行测其他45%、大作文15%、申论其他25%**。72小时约为11、32、11、18小时，复盘、读手册都计入，整卷不是额外加班。平日约55、160、55、90分钟；整卷日挪用前后两天预算，不强求日比例。

| 日期 | 主任务（其余时间用于上述日常短练、复盘） |
|---|---|
| 16日 | 行测整卷诊断；确定两个弱项和跳题问题 |
| 17日 | 申论180分钟整卷诊断，作文计入第1篇 |
| 18日 | 复盘申论；政治闭卷回忆；弱项专项 |
| 19日 | 概括、解释题；作文两份提纲 |
| 20日 | 对策题、公众应用文；弱项限时小组 |
| 21日 | 独立作文第2篇及复盘；判断或资料补漏 |
| 22日 | 第二套行测整卷，比较错因和时间分配 |
| 23日 | 短评或汇报；重写作文弱段；政治隔日测 |
| 24日 | 第二套申论整卷，作文第3篇；验证时间预算 |
| 25日 | 第三套行测整卷；复盘申论最突出问题 |
| 26日 | 只修高频失误；提纲、格式和涂卡流程检查 |
| 27日 | 缩量，只看错因和记忆薄弱点；不再开新专题 |

【经验】申论先试前四题110分钟、作文65分钟、检查5分钟；以两次整卷调整，不同时执行“先通读50分钟”和各题含阅读的预算。

【推断】若只有3小时／天，保留2次行测、2次申论整卷，作文仍以整卷为主，砍独立题量和全部新资料制作。若行测已稳定而申论写不完，从其他行测转10个百分点给申论，先看问题在作文还是前四题；政治已稳定则降至10%，空出的时间给实测弱项。只在第2天和第7天调整，避免每天换计划。

Optional hardening：无。Scope：inside task，仅公共科目咨询；不推算专业科目或总成绩收益。
